# 个股与板块的手动研究：探索路线图

日期：2026-09-22

来源：[《A 股趋势投资：研究大纲与原型阶段》阶段 1：个股与板块的手动研究](2026-09-21-a-share-trend-stock-selection-outline.md#阶段-1个股与板块的手动研究)。

面向个人 A 股趋势研究，用少量个股和板块样本，探索自己怎样观察趋势、形成判断、留下依据，并在后续变化中回看。来源已明确：个股与板块既要能独立研究，也要能相互关联；初步体验发现与买入候选的用途，保留跨阶段连续记录。日线、盘后和中期趋势是暂定起点，产品形态、研究方法、池的名称与关系仍待原型验证。以下大纲用于讨论可能需要的能力，不作为已确定的实施需求。

## 内容大纲

1. **选定研究对象与历史时点**
   - 解决“从哪里开始一轮研究”的问题：手动选择少量个股或板块，以及希望观察的历史时点，使研究有明确对象和时间背景。
   - 可能需要区分真实历史与模拟演示，并了解当时可用的信息及缺失之处。回放只使用当时可知的信息；无法还原的部分保留为未知。
   - 样本选择服务于研究方式的探索，自动扫描与批量发现继续留在来源文档的后续方向中。

2. **分别研究个股与板块的趋势**
   - 个股研究关注对象自身的走势，以及相对市场、同行的表现，探索哪些依据能帮助形成初步判断。
   - 板块作为独立对象，覆盖行业与概念的趋势观察和比较；可探索整体表现与成员参与情况是否有帮助，使板块研究本身也能留下判断与后续回看记录。
   - 两类对象可能需要不同依据，不预设共用一套筛选规则或评分。具体看哪些信息、看到什么程度，通过样本体验决定。

3. **在个股与板块之间关联研究**
   - 探索从板块寻找值得进一步查看的个股，以及从个股回看相关板块，理解两种研究路径怎样互相补充。
   - 可能需要比较个股与板块、板块与板块的表现，观察关联信息是否改变原判断。关联研究接续各对象自己的记录，不预先要求个股与板块得出相同结论。
   - 行业、概念及成员关系采用什么口径、历史关系能否还原，均留待探索；当前关系不能直接当作历史时点的关系。

4. **形成研究判断，体验发现与买入候选的分工**
   - 解决“看完之后留下什么选择”的问题：探索怎样表达当前判断、依据和仍未解决的疑问，使研究能接续下去。
   - 沿用来源文档的暂定用途：发现承载值得进一步研究的个股；买入候选承载进一步研究后、准备等待买入机会的个股。本轮通过手动研究体验这一区别，加入候选本身不代表成交或持仓。
   - 板块保留独立的研究判断和跟踪意图。是否需要板块池、怎样与个股各池关联，以及各池进入、退出和重入的条件，通过原型推敲。

5. **保留随研究推进的连续记录**
   - 解决“为什么当时这样判断，后来为什么改变”的问题：以研究对象为线索，保留当时的依据、选择和后续修正，使发现到买入候选等用途变化后的研究仍可回溯。
   - 个股与板块各自保留研究脉络，关联研究时能理解两者判断的联系。后续变化应能与原判断对照，而不是只留下最新结论。
   - 记录的详略和呈现方式待体验决定，不预设完整研究卡模板，也不要求每个池单独建立一套记录。

6. **推进时间，对照原判断复盘**
   - 通过历史回放或明确标记的模拟演示，看到作出判断之后的变化，并探索怎样保留、调整或结束当前研究。
   - 复盘既看原判断与后续变化的关系，也看研究过程：哪些信息有用、哪些缺失、哪些难理解，以及记录能否帮助接续判断。
   - 将发现的问题带回下一轮手动研究。此处积累的是原型体验发现，方法有效性仍需后续独立验证，不能由少量案例直接确定。

## 建议与取舍

- **建议从少量、有关联的个股与板块样本开始。** 这样可以体验两类对象的独立研究和双向关联，便于发现理解上的缺口。样本数量与组合保持开放，不按一次体验的结果固定方法。
- **建议先让观察、判断、记录和回看连起来，再决定池怎样呈现。** 先理解自己是否确实在做不同的研究选择，才能判断“发现”和“买入候选”的划分是否有用；暂定名称不直接替代已有正式领域术语。
- **建议按判断中的实际疑问补充信息。** 市场背景、基本面、公告与事件可以在需要时进入研究；先验证它们是否改变判断，再考虑扩展深度，不把完整信息集合设为开始研究的前提。
- **建议将本轮范围保持在手动研究。** 来源文档已安排每日自动发现、持续多池跟踪、买入与止损、持仓与卖出、批量验证等后续方向；本轮以研究用途和记录衔接为探索重点，不提前展开这些环节的完整规则。
- **每个新增能力都应能在原型中独立体验“输入 → 判断 → 操作 → 反馈 → 记录”。** 为运行而采用的临时规则标为试验假设，具体走势情境与交互放到原型中讨论。形成内容取舍时，记录对应原型与体验发现，再同步需求和术语；既有架构、数据契约与图表规范继续适用。

## 建议探索顺序

建议先选少量样本和一个历史时点，分别体验个股与板块的独立研究，并从第一轮就留下判断、推进时间和回看；这样可以先了解两类对象各自需要什么依据。随后用关联样本比较“从板块看个股”和“从个股看板块”两种路径，判断关联信息带来的帮助。在此基础上，再体验发现与买入候选的用途差别，检查用途变化后的记录能否接续。最后根据回看中暴露的缺口补充信息、调整表达方式。这个顺序是探索建议，后续范围和优先级由原型体验决定。

## 待探索

- 实际研究更常从已知个股还是板块出发？日线、盘后和中期趋势是否适合作为首轮起点？
- 个股与板块分别需要哪些依据，才能作出自己能够解释的判断？哪些信息只增加负担，哪些缺失会阻碍研究？
- 板块独立研究希望回答什么问题？行业与概念在理解、比较和关联个股时，是否需要不同处理？
- “值得进一步研究”和“准备等待买入机会”在实际体验中是否有清楚区别？现有暂定名称是否有帮助，板块是否需要单独的组织方式？
- 最少保留多少记录，才能回想当时的理由，并在日期或研究用途变化后继续使用？哪些依据需要与个股、板块的关联一起保留？
- 历史行情、板块成员及其他依据能还原到什么程度？信息缺失时，哪些研究仍可体验，哪些结论只能保持待定？
- 走完一轮后，能否具体指出有用、缺失或难理解的信息，并据此决定下一次原型要验证的问题？

## 阶段推进方案：每一步都能实操

以下四个阶段细化来源文档的“阶段 1：个股与板块的手动研究”，范围限于本路线图的六个内容方向。阶段划分与顺序均为探索建议，待原型体验后调整。

### 方向与约束

- 已明确：用少量个股和板块样本研究趋势，支持两类对象的独立研究与相互关联，体验发现与买入候选的用途，并保留跨日期、跨研究用途的连续记录；每个新功能都能立即放入实际任务中体验。
- 暂定：从日线、盘后、中期趋势及一只个股的历史研究开始，随后加入板块。原型可利用已有工具、手工记录或模拟回放形成可操作样例，载体与样本数量保持开放。
- 待原型确定：观察依据、比较方法、信息详略、池的名称与关系、记录形式、具体操作，以及各阶段的先后取舍。原有探索建议不因分阶段而成为确定需求。
- 每阶段保留 **输入 → 查看依据 → 做出选择 → 看到反馈 → 留下记录**。先保存当时判断，再推进时间查看后续变化；可用历史回放或明确标记的模拟资料提前体验反馈。
- 本轮沿用手动研究范围。自动发现、完整多池跟踪、交易与止损、批量方法验证仍由来源文档的后续方向承接；这里的用途变化只用于体验研究分工和记录衔接。

### 阶段总览

| 阶段 | 目标 | 可体验的闭环 |
| --- | --- | --- |
| 1. 个股研究与回看 | 完成一只个股的趋势判断，并对照后续变化回看依据 | 选个股与历史时点 → 查看走势 → 保存判断 → 推进时间查看变化 → 复盘留痕 |
| 2. 板块独立研究与比较 | 完成板块自身的研究，探索比较信息是否有帮助 | 选板块与历史时点 → 查看板块及本轮比较依据 → 保存判断 → 推进时间查看变化 → 回看记录 |
| 3. 个股与板块联动研究 | 理解两类对象的关联信息是否影响各自判断 | 选已有研究对象 → 查看关联对象 → 保存两者判断 → 推进时间对照变化 → 记录关联信息的作用 |
| 4. 发现与买入候选的分工 | 体验两种研究用途的区别，并让记录接续 | 选已研究个股 → 判断是否准备等待买入机会 → 记录用途选择 → 推进时间重新判断 → 回看连续依据 |

先分别走通个股与板块的研究，再探索两者联动，最后体验研究用途的区分；顺序与范围可依据体验调整。对象与历史时点选择、最小记录和回放从阶段 1 开始贯穿全程，后续逐步增加板块比较、关联依据及用途变化后的记录衔接。各阶段内的新增信息或研究路径逐项接入已有闭环，每加一项即可体验，无需等同阶段其他能力全部齐备。市场背景、基本面、公告与事件按当轮实际疑问少量补充，再回看它们是否影响判断，不单独扩展为完整信息模块。

### 阶段 1：个股研究与回看

- **目标：** 完成一只个股的趋势判断，并对照后续变化回看依据。
- **内容范围：** 承接对象与时点选择、个股独立研究、研究判断、连续记录和回放。先观察自身走势；相对市场、同行的比较可逐项加入，每次复用同一研究与回看链路。
- **体验闭环：** 选择一只个股和历史时点 → 查看当时可知的走势与本轮依据 → 写下当前判断、理由及疑问 → 推进时间查看变化 → 对照原判断，留下复盘与下一次研究的问题。
- **完成依据：** 能回想并解释当时判断，对照后续变化指出有用、缺失或难理解的信息；若加入比较依据，能说明它是否影响判断。观察方法与记录详略保持可调整。

### 阶段 2：板块独立研究与比较

- **目标：** 完成板块自身的研究，探索比较信息是否有帮助。
- **内容范围：** 将已有闭环用于行业与概念板块的独立研究，保留板块自身的判断与跟踪意图。先研究一个板块，再逐项体验板块间比较、相对市场表现或成员参与情况；行业与概念可分别体验，不预设共用规则。
- **体验闭环：** 选择板块与历史时点 → 查看板块自身走势，按需补充本轮比较依据 → 保存板块判断和继续研究的选择 → 推进时间查看板块变化 → 对照原判断，记录本轮依据是否有帮助。
- **完成依据：** 能在不依赖某只个股结论的情况下完成板块研究；加入比较或成员信息后，能解释它对判断的作用或局限。分类口径和板块是否需要单独的池继续待探索。

### 阶段 3：个股与板块联动研究

- **目标：** 理解两类对象的关联信息是否影响各自判断。
- **内容范围：** 承接个股与板块的关联研究，复用两类对象各自的判断、记录和回放。分别体验从板块寻找个股、从个股回看板块，两条路径均可单独走通；成员关系使用当时可知的资料，无法还原的部分保留为未知。
- **体验闭环：** 选择已有个股或板块记录 → 沿本轮路径查看关联对象 → 比较自身与关联对象的依据并保存各自判断 → 推进时间对照两者变化 → 记录关联信息是否改变判断及仍存疑问。
- **完成依据：** 两条路径各能完成一轮研究与回看，并能指出关联信息有用、无用或不足之处；两类对象的原判断与后续修正均可追溯，允许结论不同。

### 阶段 4：发现与买入候选的分工

- **目标：** 体验两种研究用途的区别，并让记录接续。
- **内容范围：** 承接研究判断、发现与买入候选的暂定分工，以及跨用途连续记录。复用已有个股与相关板块依据，体验“值得进一步研究”与“准备等待买入机会”的差别；板块保留独立判断和跟踪意图，暂不固定池间流转规则。
- **体验闭环：** 选择已研究的个股及原有记录 → 判断现有依据是否足以准备等待买入机会 → 保存本次用途选择、理由和待解疑问 → 推进时间查看后续变化并重新判断 → 对照选择前后的依据，留下可接续的记录。
- **完成依据：** 能从实际样本说明两种用途是否有清楚区别，并在用途保持或改变后找回原有研究脉络；若区别不清，也能记录具体困惑，作为调整名称或边界的依据。加入买入候选不代表成交或持仓。

## 原型与文档如何配合

- 规划文档保持目标、内容范围、体验闭环、完成依据和待验证问题的大纲粒度。具体走势情境、操作、规则与信息呈现通过原型推敲，文档中的阶段安排仍可调整。
- 每次围绕一个明确研究任务，提供可操作样例、反馈和回看记录。为走通体验而采用的临时规则标为试验假设，每项新增能力接入已有闭环后立即体验，再决定是否保留或扩大范围。
- 真实历史、最新可用资料与模拟演示分别标明。历史回放只使用当时可知的信息，包括历史板块关系；资料不足保留为未知。流程能走通、信息有帮助与方法有效分别判断，少量样例不能证明投资效果。
- 记录以能回看输入、当时依据、选择和后续结果为限，可复用已有方式。形成结论时注明对应原型、体验发现及已确定的取舍，再同步相关需求和术语；前文未解决的探索问题继续保留。
- 工程能力随闭环按需增加，继续遵守项目已生效的分层架构、数据契约和图表规范；阶段完成依据用于后续体验判断，本文补充不表示这些能力已经实现或验证。

下一步建议从阶段 1 的“一只个股、一个历史时点、一轮判断与回看”开始，先体验观察、保存判断、推进时间和复盘的完整链路，再决定需要补充哪些依据及怎样记录；最终产品形态保持开放。
