# A 股趋势投资：研究大纲与原型阶段

日期：2026-09-21

本文记录个人 A 股趋势投资的研究范围和可体验阶段。产品形态尚未确定，每阶段通过原型完成一个实际任务，再根据体验调整后续方向。本文保持大纲粒度，具体功能取舍、名称、规则和参数须通过原型推敲后确定。

## 研究内容大纲

1. **个股与板块的趋势研究**
   - 同时研究对象自身的趋势，以及相对市场、同行的强弱。
   - 板块是独立研究对象，覆盖行业与概念的发现、比较、跟踪和复盘，也支持从板块寻找个股、从个股回看板块。
   - 中期趋势、相对强弱和基本面复核是初始研究方向，具体方法由原型探索。相对强弱可参考[动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Fact-Fiction-and-Momentum-Investing)，其证据不能直接证明某套 A 股规则有效。

2. **分清扫描范围与各池的用途**
   - 扫描范围定义可以研究哪些股票；证券状态、数据覆盖、流动性、交易权限及风险如何影响各环节，留待原型验证。
   - 暂以“发现池、买入候选池、持仓池”组织个股研究，分别承载策略发现、等待买入和持仓管理。
   - 池的划分建议见下文；进入、退出、重新进入和池间关系尚未定稿。

3. **每日发现与筛选**
   - 按每个交易日重复扫描和查看组织体验，同时覆盖个股和板块；可先从盘后场景开始。
   - 个股由策略、因子等形成发现结果，再进一步研究和筛选买入候选。
   - 同时查看新发现、已有对象的变化和待处理判断；每日查看不等于每日交易，周期复盘可以另外保留。

4. **市场背景与板块趋势**
   - 研究市场趋势、广度及其对判断的影响。
   - 研究板块自身趋势、相对强弱、成员参与及变化，保留板块独立研究和跟踪的入口。
   - 板块与个股的筛选方法、分类口径及联动方式通过原型决定，不预设使用同一套规则。

5. **贯穿各池的研究记录与基本面复核**
   - 建议以研究对象为线索，保留从发现、候选、持仓到退出复盘的连续记录，各阶段按需要补充依据。
   - 基本面、公告与事件复核在有判断需求时进入各阶段，不局限于候选池；信息缺失保留为未知。
   - 板块保留自身的研究记录，并可关联个股。研究卡、时间线或其他呈现形式由原型决定，不要求每个池各建一张卡。

6. **持续跟踪与重新判断**
   - 持续查看各池对象及板块的趋势变化，对照原始依据重新判断。
   - 不同走势、突发变化和相应操作在原型中探索，此处不展开情形清单、状态机或处理规则。

7. **买入、持仓与卖出决策**
   - 买入：研究候选是否值得行动、买入时机、仓位及风险计划。
   - 持仓：研究是否继续持有，以及是否需要调整仓位或原有计划。
   - 卖出：研究退出理由、执行与事后复盘，保留当时的判断依据。
   - 这些环节都有独立决策，具体动作与条件通过原型逐步推敲。

8. **止损线与风险管理**
   - 止损是核心探索内容，从买入计划开始，贯穿持仓、卖出和复盘。
   - 探索止损依据、初始设置、后续调整、触发后的决策与执行，以及和仓位风险的关系。
   - 具体策略、计算方法、阈值及触发规则由原型比较后确定。止损计划与实际成交分别记录，不能将止损线视为保证成交价；模拟执行须考虑适用的[交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。

9. **复盘与方法验证**
   - 分别检查个股与板块发现、候选筛选、买入、持仓、卖出和止损的作用。
   - 通过历史回放、批量比较和模拟跟踪积累证据，保留规则版本、当时可知的信息及失败案例。
   - 区分流程能否使用、判断是否有帮助与策略是否有效，候选表现不直接等同于可实现收益。

## 池的划分建议：先保留三个主要用途

三个池足以作为首轮原型的起点。“买入候选池”比“候选池”更能表达等待买入的用途；以下名称和边界均为讨论建议。

| 概念 | 建议用途 | 当前定位 |
| --- | --- | --- |
| 扫描范围 | 定义策略和研究覆盖的股票集合 | 作为上游范围配置，暂不增加为一个业务池 |
| 发现池 | 收集策略、因子等发现的值得进一步研究的股票及依据 | 解决“有哪些对象值得看” |
| 买入候选池 | 承载从发现结果中进一步筛选、研究后，等待买入时机的股票 | 解决“哪些对象值得准备行动” |
| 持仓池 | 承载已经实际买入或模拟成交的股票及持仓决策 | 解决“已持有对象接下来怎么办”，买入计划本身不等于持仓 |
| 历史归档 | 保留结束研究、未采用对象及交易结束后的复盘记录 | 先作为各阶段的历史记录，不单独增加一个操作池 |

“发现 → 买入候选 → 成交后持仓 → 复盘”是用于体验的主路径，不代表已确定单向流转或互斥规则。是否回退、重入、同时出现在不同视图，以及是否还需要其他池，均通过原型判断。

板块单独承载发现、研究和持续跟踪，可以关联各股票池；是否需要板块池及如何命名待体验决定，不机械套用个股的持仓概念。

现有领域文档中的“自动候选”等词语与本轮“买入候选池”不直接等同。本轮命名保持为探索用语，待原型验证后再统一正式术语和相关文档。

## 阶段推进方案：每一步都能实操

### 方向与约束

- 已明确：个人 A 股趋势研究同时包含个股与板块；按交易日持续发现和查看；覆盖多池管理、买入、持仓、卖出和止损决策；每个新功能都能立即体验。
- 暂定：从日线、盘后、中期趋势和小规模样本开始，原型可以采用历史回放或模拟操作。
- 待原型确定：最终产品形态、池的名称与关系、具体操作、策略参数、止损方法、自动化程度及各阶段的先后取舍。
- 每阶段保留 **输入 → 查看依据 → 做出选择 → 看到反馈 → 留下记录**。涉及后续变化时可以回放，形成闭环无需等待真实市场经过数周。

### 阶段总览

| 阶段 | 目标 | 可体验的闭环 |
| --- | --- | --- |
| 1. 个股与板块的手动研究 | 找出研究对象、判断依据和记录方式 | 查看样本 → 研究个股或板块 → 记录选择 → 推进时间 → 回看 |
| 2. 每日发现与候选筛选 | 体验持续发现和进一步筛选的分工 | 当日扫描 → 查看个股与板块发现 → 筛选买入候选 → 记录依据 → 次日比较 |
| 3. 多池与板块持续跟踪 | 理解跨日期、跨阶段的变化及待处理判断 | 打开各池与板块记录 → 查看变化 → 做判断 → 保留记录 → 次日接续 |
| 4. 研究依据与决策记录 | 验证市场、基本面等证据如何帮助各阶段判断 | 查看对象 → 核查证据 → 保留或调整判断 → 更新记录 → 回放复核 |
| 5. 买入计划与初始止损 | 体验从等待机会到承担持仓风险的决策 | 选择候选 → 制定买入、仓位与止损计划 → 模拟执行 → 查看持仓或未成交结果 → 复盘 |
| 6. 持仓、卖出与止损调整 | 体验持有期间的反复决策和退出过程 | 查看持仓及相关板块 → 复核计划与止损线 → 做持有或调整、卖出决定 → 模拟执行 → 复盘 |
| 7. 批量回放与方法验证 | 比较各环节的价值并决定保留什么 | 固定待验证方案 → 运行历史样本 → 对比结果 → 回看案例 → 保留或修改 |

各阶段是探索路线，后续可依据原型反馈调整顺序和范围。日常复盘贯穿全程，阶段 7 只增加批量比较能力。

### 阶段 1：个股与板块的手动研究

- **目标：** 用少量个股和板块样本，找出自己怎样观察趋势、做判断和留下依据。
- **内容范围：** 个股与板块的独立查看和相互关联，初步体验发现与买入候选的用途，以及跨阶段连续记录。
- **体验闭环：** 选择历史时点 → 查看个股或板块 → 记录研究判断 → 推进时间 → 对照原判断复盘。
- **完成依据：** 能走完一轮研究并指出有用、缺失或难理解的信息；池的命名和呈现方式仍可调整。

### 阶段 2：每日发现与候选筛选

- **目标：** 将有用的策略或因子变成可以每天重复运行和查看的发现流程，再进一步筛选买入候选。
- **内容范围：** 个股与板块各自的发现方法、个股发现池与买入候选池的分工、当天结果与历史结果的联系。选定策略、范围和依据须能看懂。
- **体验闭环：** 扫描某交易日 → 查看发现及原因 → 研究并筛选买入候选、选择跟踪板块 → 保存判断 → 推进至下一交易日再次扫描和比较。
- **完成依据：** 能连续体验多个交易日，理解新发现和原有对象的变化。每日扫描与人工查看先跑通，调度、通知及具体运行时点在原型中决定。

### 阶段 3：多池与板块持续跟踪

- **目标：** 持续跟踪已有对象，理解各阶段需要做哪些判断，以及它们如何接续。
- **内容范围：** 发现、买入候选、持仓的查看与研究记录，板块独立跟踪、个股关联和历史复盘。早期可以用模拟持仓体验，后续接入模拟成交结果。
- **体验闭环：** 打开既有记录 → 查看对象及板块变化 → 作出当前判断 → 留下依据 → 推进日期后继续跟踪。
- **完成依据：** 能接续前一次判断并回溯理由。不同走势下怎样操作、是否改变所属池或结束研究，在原型中用情境推敲，本文不展开。

### 阶段 4：研究依据与决策记录

- **目标：** 找出市场背景、基本面和事件信息怎样帮助发现、候选及持仓阶段的决策。
- **内容范围：** 股票与板块的研究依据、信息来源、阶段变化和决策记录；按实际疑问补充信息，避免预先固定完整研究卡模板。
- **体验闭环：** 从任一阶段选择对象 → 核查一类证据 → 保留或调整判断 → 补充连续记录 → 回放检查依据的作用。
- **完成依据：** 能说明新增信息改变了什么判断，各阶段的记录可以衔接。市场背景和基本面等可分别做小原型，每完成一项就体验一次闭环。

### 阶段 5：买入计划与初始止损

- **目标：** 从买入候选出发，体验买入时机、仓位和初始止损如何共同形成一个行动计划。
- **内容范围：** 等待或买入的判断、计划与执行、初始止损依据及设置、成交后持仓与研究记录的接续。
- **体验闭环：** 研究候选 → 制定买入、仓位及止损计划 → 推进时间并模拟执行 → 查看实际模拟结果 → 对照计划复盘。
- **完成依据：** 能解释行动或继续等待的理由，区分计划与成交，理解止损安排对应的风险；具体策略和条件由原型产生。

### 阶段 6：持仓、卖出与止损调整

- **目标：** 体验买入之后持续持有、仓位调整、退出及止损管理中的决策。
- **内容范围：** 持仓与板块变化、原有依据复核、止损线维护、卖出决策及执行、退出后的研究与复盘。
- **体验闭环：** 查看持仓 → 对照依据与风险计划 → 作出持有、调整或卖出判断 → 查看模拟执行结果 → 复盘并接续后续研究。
- **完成依据：** 能回溯持仓期间的重要判断、止损设置和调整理由，并对照执行结果。具体走势、触发方式、调整条件和池间流转留在原型中讨论。

### 阶段 7：批量回放与方法验证

- **目标：** 检查原型中形成的方法在更多样本上的表现，分辨发现、筛选、交易和止损各环节的作用。
- **内容范围：** 个股与板块发现的比较、多池筛选的作用、买入与持仓管理、卖出及止损方案的比较。
- **体验闭环：** 固定一个待验证方案 → 批量回放 → 查看对照与失败案例 → 返回原型检查判断 → 保留或修改方案。
- **完成依据：** 结论有可追溯的规则、样本和对照，明确数据不足与验证局限；候选后续表现和含成交、仓位、成本的组合结果分别评价。

## 原型与文档如何配合

- 规划文档只记录阶段目标、内容范围、体验闭环和待验证问题；每阶段的实际行为与参数在原型里推敲。
- 原型每次围绕一个明确任务，提供可操作样例、反馈和回看记录。为运行而采用的规则标为试验假设，经体验验证后才形成正式需求。
- 真实历史、最新可用数据和模拟演示分别标明；回放只使用当时可知的信息。演示案例不能证明投资效果。
- 保留研究对象、当时依据及后续决策，区分原型体验结论与方法有效性证据；验证后的术语与规则再同步到正式文档。
- 工程能力随闭环按需增加；现有架构、数据契约和已生效的图表规范继续适用。

下一步建议从阶段 1 的个股与板块小原型开始，先体验研究与记录，再决定怎样划分池和安排后续操作；暂不锁定页面结构、技术栈或最终产品形式。
