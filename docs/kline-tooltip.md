# 股票详情页 K 线 Tooltip 展示业务逻辑

> 更新日期：2026-09-12。本文对齐已经确定的[图表显示规范](2026-09-06-kline-display-and-indicators-spec.md)第 6.4、6.5、9 节，补充[统一行情数据契约](2026-09-12-market-data-contract.md)输入引用；本次不新增或改变 UI 表现。
>
> 早期文稿是旧实现行为记录，其中含昨收回退、总股本回退、缺失补零和 hover 边界问题，现[原文归档](archive/2026-09-06-kline-tooltip-legacy.md)。这些记录不构成新系统要求；现行 UI 规则以显示规范为准。

## 1. 用途与数据边界

Tooltip 查看活动蜡烛的行情明细。全部字段属于同一标的、周期、时间与系列快照；不能混入最新 Tick、其他股票或其他版本。已有日线及 1、5、15、30、60 分钟业务均使用相同 11 行；当前显示规范的交付范围仍是日 K 和 1 分钟，本次不扩展图表周期功能。

Tooltip 接收数据服务按统一契约提供的标准行情。来源字段和单位差异由适配层在入库前处理，服务保持标准值及现有 UI 名称映射；前端不判断 QMT 或第三方，不接收未知单位后自行猜测。

- `volume` 为该根 K 线成交量，股票固定手；数据库、服务传递相同单位。
- `amount` 为该根 K 线成交额，固定人民币元。
- `changeRate/turnoverRate` 为小数比例；0.05 表示 5%。
- `prevClose` 对应标准 `prev_close`；`tradeTime` 由标准交易日/分钟标签映射，不能直接沿用未经验证的源时间。
- 价格、量额、比例的目标持久类型和精度见统一契约；只在最后展示时按 UI 规则舍入，格式化结果不能回写事实或作为信号输入。

## 2. 固定字段、单位与颜色

缺值仍保留字段名称与顺序，不因来源不同增删行。

| 顺序 | 展示名称 | UI 输入与既有展示规则 | 颜色 |
| --- | --- | --- | --- |
| 1 | 时间 | `tradeTime`：上海日期 / 日期与时分。 | 灰色。 |
| 2 | 昨收 | `prevClose`：可信、有限且大于 0 时两位小数，否则 `--`。 | 黑色。 |
| 3 | 开盘 | `open`，两位小数。 | 与可信昨收分别比较，高红、低绿、等于或基准不可得为黑。 |
| 4 | 收盘 | `close`，两位小数。 | 同上。 |
| 5 | 最高 | `high`，两位小数。 | 同上。 |
| 6 | 最低 | `low`，两位小数。 | 同上。 |
| 7 | 涨跌额 | `changeAmount`，经第 3 节校验，两位小数，正数加 `+`。 | 最终未舍入值正红、负绿、零或不可得为黑。 |
| 8 | 涨跌幅 | `changeRate * 100`，两位小数加 `%`，正数加 `+`。 | 与涨跌额共用可信输入，方向一致。 |
| 9 | 成交量 | `volume / 10000`，固定万手；小额规则见下文。 | 黑色。 |
| 10 | 成交额 | `amount / 100000000`，固定亿；小额规则见下文。 | 黑色。 |
| 11 | 换手率 | `turnoverRate * 100`，两位小数加 `%`，不加正号；缺失为 `--`。 | 黑色。 |

价格和涨跌额不追加元，不使用千位分隔符。正负号和颜色使用最终未舍入值，不能因为显示为零就判平盘；极小涨跌仍可显示 `+0.00/-0.00`。四价颜色按昨收比较，不套用蜡烛按 open/close 判色的规则。

成交量与成交额的换算值记为 x：真实 `x=0` 显示 `0.00`；`0<x<0.01` 显示 `<0.01`；其余按两位小数四舍五入，随后追加万手或亿。单位不随数值大小改变。10 手显示 `<0.01万手`，100 手显示 `0.01万手`；10 万元显示 `<0.01亿`，100 万元显示 `0.01亿`。动态图例沿用同规则，柱高和坐标计算使用未舍入数值，不能把阈值字符串用于绘图。

真实零、缺失、非有限和非法负量额分别处理；未知不补零，异常显示 `--`。比例 0.05 显示 5.00%，不能传入百分数数值 5 再乘 100。

## 3. 基准与计算口径

### 3.1 昨收、涨跌额与涨跌幅

昨收是活动 bar 所属交易日的上一交易日同口径收盘基准。同一日全部分钟共用该基准，跨日逐日取得；不能回退结算价、上一分钟 close 或缺口之前恰好有数据的价格。上游前收候选须先经来源契约验证，否则由服务读取标准上一交易日日线，仍不可得时显示 `--`。

可信 close 与正昨收齐备时：

```text
changeAmount = close - prevClose
changeRate = (close - prevClose) / prevClose
```

涨跌两项作为一组验证，服务结果必须对应同一 bar、基准与快照。逐项与期望值比较的数值误差上限沿用显示规范：`max(1e-9, 1e-12 * max(abs(actual), abs(expected)))`，正、负、零方向也必须一致；容差不能把极小真实涨跌改为零。

可信输入完整时补齐缺失项；任一结果矛盾、非有限或超差时统一重算两项，显示既定“涨跌数据已校正”状态并保留原值供诊断。输入不足时两项均为 `--`，标明昨收基准或收盘价不可用，不凭一个服务结果反推另一项。正确且已验证的零值保留，不因真假值判断被覆盖。

校验和计算可由既有数据服务完成，Tooltip 消费同批结果与状态；此处不新增前端重复计算或来源判断。异常说明仍使用对应行状态文案，不增减 11 行。

### 3.2 换手率

```text
成交股数 = volume（手） * 100
turnoverRate = 成交股数 / 该 bar 交易日有效的流通股本（股）
UI 百分数 = turnoverRate * 100
```

两次乘 100 分别用于手转股和比例转百分数，不能混用。服务负责计算，Tooltip 仅显示比例，不因未带股本明细而自行补算。

流通股本必须为有限正值，且来源、生效区间、可得时间和版本可验证；不能回退总股本，也不能使用今天股本填补未知历史。已提供比例同样必须通过该口径验证。股本变化或修订后重算受影响结果；缺失时显示 `--` 和既定“历史流通股本不可用”状态。

20000 手与当日有效流通股本 100000000 股得到比例 0.02，显示 `2.00%`。volume 真实零且分母有效得到 `0.00%`；volume 缺失或分母无效时为 `--`。成交额不能以 close 乘成交量代替。

## 4. 时间与主副图联动

日线显示 `YYYY-MM-DD`，分钟显示 `YYYY-MM-DD HH:mm`，使用 `Asia/Shanghai`。带时区时间先转换；例如 UTC `2026-03-02 16:00` 对应上海 `2026-03-03 00:00`。正式服务输入应已经由契约确定交易日和时间标签。

既有异常展示兜底保持不变：无时区旧输入按上海理解；通过横向位置命中但时间无法解析时保留原文本，缺失则 `--`，不猜日期。这只是 UI 容错，不能使未知时间通过标准数据入库验收。

主图或副图命中有效时间时，共享同一 11 行行情 Tooltip，并显示完整 X 轴时间和当前绘图区自己的 Y 轴坐标。副图 Y 值是鼠标纵向位置在该副图坐标系的值，不是主图价格，也不要求吸附指标曲线；指标实际值在动态图例显示。主副图之间移动保留有效活动时间，只切换横线和 Y 标签归属。

切到 MACD/RSI 仍显示 Tooltip 的成交量、成交额和换手率，不额外恢复成交量副图。MA/BOLL/MACD/RSI 数值仍属于主副图图例，不加入行情明细；信号标记详情的优先规则沿用显示规范。

## 5. 显隐、刷新与位置

| 场景 | 既有目标行为 |
| --- | --- |
| 初始化完成，有可视蜡烛且无悬停 | 默认展示当前可视范围最右侧实际 bar，位于主图左上附近；无悬停不显示十字光标和 hover 轴标签。 |
| 主图或副图命中有效时间 | 显示并同步该时间 11 行、动态图例与 X/Y 标签；直接从外部进入副图也一样。 |
| 离开主副图整体、空白或无法匹配 | 隐藏浮层与临时轴标签；曾只显示默认浮层也要隐藏。重新有效命中后再显示。 |
| 无悬停时视窗变化或新 bar 到来 | 默认活动 bar 随视窗更新；默认浮层若仍可见则更新，已隐藏时不自动弹出。 |
| 同时间 bar 更新 | 按时间重新读取新版本，保留选择并刷新数值，不等鼠标再次移动。 |
| 看历史时新 bar 到来 | 保留仍有效的历史选择，不跳最新。 |
| 选中 bar 移除或不再可见 | 清除旧选择并隐藏，图例回到新可视范围最右 bar；下一次有效命中再显示。 |
| 股票/周期切换、初次加载、失败、无数据 | 清除旧浮层，不混用其他标的/周期；同视图刷新按显示规范第 13.2 节保留带更新状态的上次快照并整体替换。 |

主图 hover 时优先指针右下，右侧不足放左侧，底部不足向上限制。副图 hover 时同一浮层保留主图内上次有效位置，没有位置则使用主图左上附近。初始化、重入和尺寸变化时重新限制边界。

沿用白底、浅边框、阴影、左字段右数值、不截获指针的样式。参考宽度 210px、边缘至少 8px；窄屏自适应并允许长值换行，不能遮住图例、工具栏、轴标签或新增点击固定/拖动/关闭交互。触屏建议、动画及其他外观沿用显示规范与已有设计，本次不另作产品决定。

## 6. 示例与验收

以下为人工示例：可信昨收 10，开盘 10.2、收盘 10.5、最高 10.6、最低 9.9，标准量 20000 手、额 150000000 元、当日有效流通股本 100000000 股。

| 展示项目 | 结果 |
| --- | --- |
| 昨收 / 开盘 / 收盘 / 最高 / 最低 | `10.00 / 10.20 / 10.50 / 10.60 / 9.90`；昨收黑，前三个高于昨收价格红，最低绿。 |
| 涨跌额 / 涨跌幅 | `+0.50 / +5.00%`，红色。 |
| 成交量 / 成交额 | `2.00万手 / 1.50亿`，黑色。 |
| 换手率 | `2.00%`，黑色；历史流通股本不可用时 `--`。 |

- 来源 A 返回 20000 手，来源 B 返回 2000000 股，均先归一为 volume=20000；同样 UI 输入得到同样展示。
- 成交额原始千元与元先归一为标准元；数据库和服务不存/传亿值作为 amount。
- 缺失、真实零、非法值、小额正值、涨跌结果矛盾、跨日昨收与历史股本缺失按既有规则验收。
- 主副图 hover、完整 X 时间、独立 Y 坐标、切换/刷新/离开、窄屏和图例按显示规范既有 A01～A59 中相关场景验收。
- 数据库目标精度、来源转换及原始证据按统一契约验收；图表显示结果和交互需要真实浏览器验证。
