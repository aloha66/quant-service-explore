# 大盘、板块与个股趋势研究及观察决策：探索路线图

日期：2026-10-03

来源：[A 股趋势投资：研究大纲与原型阶段](2026-09-21-a-share-trend-stock-selection-outline.md)，重点为“阶段 1：大盘、板块与个股趋势研究及观察决策”及贯穿各阶段的策略组合、适用性与追溯约束。

面向个人 A 股趋势研究，以手动指定的少量个股与历史时点为起点，首轮优先体验“大盘趋势 → 相关板块趋势 → 个股趋势 → 观察选择 → 时间推进与三层复核”的探索路径。每层研究都保留自己的依据、结论或未知，以及能够再次使用的方法，再探索这些判断怎样共同支持是否观察、继续观察或结束观察的选择。研究既要留下这次选择的理由，也要逐步形成能够组合和替换的判断方法。产品形态尚未确定；这一顺序和各层组合方式仍是待原型验证的探索方向，具体功能取舍、规则与交互通过实际体验形成结论，既有架构、数据契约和图表规范继续适用。

## 内容大纲

1. **明确本轮研究对象与问题**
   - 围绕给定个股、研究时点和试验方法，说明本轮希望判断什么，明确所用大盘参照、相关板块及分类或成员口径、各层观察周期，以及作出判断需要哪些输入，避免依据不断增加却无法形成选择。
   - 区分真实历史与明确标记的模拟输入，只使用研究时点当时可知的信息；方法与适用假设随本轮研究一同保留。

2. **分别研究大盘、相关板块与个股趋势**
   - 先体验大盘趋势研究，再研究给定个股的相关板块趋势，最后研究个股趋势。每层结合本轮需要的原始数据、派生因子和人工解释，保留自己的支持与反对依据、结论或未知，以及可复用方法；上层结论怎样成为下一层的输入，通过原型推敲。
   - 可探索趋势与动量、相对强弱、量价关系、波动与回撤，以及本轮方法所需的市场广度、板块成员参与、基本面、公告和事件信息。每轮选择一组标为试验假设的依据，范围随研究问题确定。
   - 本轮仍围绕给定个股研究大盘与相关板块；面向更大范围的板块与股票发现、集合比较及板块独立跟踪，由来源大纲阶段 2 接续。

3. **识别情境并检查方法适用性**
   - 探索如何根据各层依据理解大盘、板块和个股所处的情境，解释为什么此时分别采用这些研究方法，以及组合后哪些适用条件仍不清楚。
   - 情境识别与适用性检查本身也可沉淀为策略，与后续依据组合和观察方法接续。资料不足时保留未知，具体识别和复核方法留待原型比较。

4. **组合三层判断与其他依据，形成观察选择**
   - 探索大盘、板块和个股的判断及其他必要依据怎样共同支持观察、继续观察、结束观察或暂缓判断，留下选择理由、疑问和后续关注点；人工解释也属于判断依据。
   - 理解各层判断和单项依据对组合结论的贡献，以及冲突或缺失时还能支持多大范围的结论。研究顺序不预先决定上下层的约束关系；是否由某层否决后续观察、组合方式、冲突处理和自动化程度均为待验证内容。
   - 观察判断可以由情境识别、依据组合与观察策略共同形成；值得观察与准备买入的判断在后续任务中分别探索。

5. **推进时间，复核三层依据与原判断**
   - 接续同一个股的研究，通过历史回放复核大盘、相关板块和个股三层依据、判断及策略适用性的变化，对照原理由重新选择并记录，体验继续观察、结束观察或暂缓判断后的反馈。
   - 探索能否区分对象不再值得观察、方法可能不再适用和资料不足，并说明本轮是在更新对象判断，还是调整所用方法。单次结果不符合预期不直接证明方法失效。
   - 反馈关注依据、疑问和判断怎样变化，使阶段 1 在给定对象上能够独立完成一轮研究与复核。

6. **保留可复用的方法与连续研究记录**
   - 逐步沉淀大盘、板块与个股的趋势研究方法，以及情境识别、依据组合和持续观察策略，说明各自解决的问题、所需输入、适用假设、输出用途和复核依据；探索替换其中一项后，其余方法能否继续复用并解释判断差异。
   - 以个股为线索保留三层当时可知的依据、结论或未知、观察选择理由、所用策略及组合版本和后续反馈。调整方法后保留新旧区别，历史判断继续关联当时版本，支持回看与再次使用。
   - 研究记录同时积累原型体验发现；体验后确定的功能取舍与仍待验证的方法效果分别保留，作为后续探索的依据。

## 建议与取舍

- **建议首轮缩小体验范围。** 可沿用来源文档中暂定的日线、盘后、中期趋势方向，从少量对象、一组试验依据和一轮时间推进开始，先看这些依据是否帮助解释和复核观察选择；样本、观察周期和回放长度仍待体验确定。
- **建议先体验三层研究，再形成观察选择。** 大盘、相关板块和个股各自解释依据并保留判断或未知，再与其他必要信息共同形成观察选择。发现缺少关键依据时，补齐依据、收窄结论或暂缓判断，并记录原因；是否继续扩展依据，由它对当前问题的帮助决定。
- **建议通过替换比较理解方法分工。** 在相同研究对象和时点下比较替换某项依据或策略前后的理由与选择，观察能否解释差异、复用其余部分。这是检验组合是否有助于研究的试验建议，具体组合规则通过原型形成。
- **沿用来源中的池衔接方向，承载方式待验证。** 阶段 1 的研究对象、依据和观察判断记录主要向发现池积累；持续观察怎样接续、是否需要单独组织，通过体验决定。范围内发现与集合选择接续阶段 2，买入准备接续阶段 3，本轮重点保持在给定个股的观察判断。
- **区分体验发现与有效性证据。** 能完成研究与复核、能解释选择、能复用方法，分别提供不同层面的反馈。阶段 1 的观察任务不以最终交易盈利作为完成条件；方法有效性及组合整体的效果仍需独立验证，局部方法形成后即可接续阶段 5 的探索。

## 建议探索顺序

建议从一个给定个股、历史时点和明确观察问题出发，说明大盘参照、相关板块口径和各层观察周期，优先体验“大盘趋势 → 相关板块趋势 → 个股趋势 → 观察选择 → 时间推进与三层复核”。每层先保留依据、结论或未知和试验方法，再解释它怎样参与观察判断；推进时间时同时复核三层依据与策略适用性。每次体验都接续“输入 → 判断 → 操作 → 反馈 → 记录”，同步保留所用方法和版本，便于回看当时的理由。

在这项任务能够独立完成之后，再比较替换各层依据、研究方法或组合方式的不同方案，逐步理解哪些部分值得复用、哪些需要人工解释，以及方法改变后历史记录怎样接续。研究顺序和上下层是否构成否决条件分别验证；来源大纲阶段 2 可据此扩展对象来源、集合比较和板块独立跟踪，具体先后取舍仍由原型反馈调整。

## 待探索

- 首轮选择哪些个股、时点与观察问题？大盘参照、相关板块口径和各层观察周期怎样说明，哪些依据是本轮必要输入？
- 大盘、板块、个股三层能否分别形成可解释的结论或未知及可复用方法？先研究大盘、再板块、再个股，是否帮助理解和复核观察选择？
- 各类因子及其他依据分别怎样帮助或质疑选择？哪些解释需要人工保留，哪些能力值得自动化？
- 各层趋势研究、情境识别、依据组合与观察策略怎样分工？替换一层的方法或一项依据后，能否解释组合结论的变化并复用其余部分？
- 各层判断冲突或依据缺失时，怎样保留未知并确定本轮能够作出的结论？是否需要某层否决后续观察？能否区分对象变化、方法适用性变化和证据不足？
- 什么时候值得重新查看，哪些变化值得重新判断？怎样通过回放复核三层依据与策略适用性，获得有助于重新选择的反馈，避免把事后信息带回原判断？
- 持续观察与结束观察怎样接续记录，发现池如何承载这项任务？哪些原型体验发现足以形成具体功能取舍，哪些仍需扩大样本或独立验证？

## 阶段推进方案：每一步都能实操

### 方向与约束

- 本节将来源研究大纲的“阶段 1：大盘、板块与个股趋势研究及观察决策”细分为三个探索步骤。下文阶段编号仅指这三个步骤；前文提及的阶段 2、3、5 仍指来源大纲中的发现与选择、买入判断、策略独立验证。
- 已明确：围绕手动指定的个股与历史时点，研究大盘、相关板块和个股趋势，各层保留依据、结论或未知及可复用方法，形成观察、继续观察、结束观察或暂缓判断的选择，并通过时间推进复核三层依据与策略适用性；每个新功能都能接入这项实际任务立即体验。
- 已明确：本轮输入说明大盘参照、相关板块口径和各层观察周期，本轮方法所需的基本面与事件信息随当前判断一起提供；情境识别、适用性检查、可复用方法及组合版本的追溯从首次使用起进入闭环。关键资料不足时，补齐、收窄结论或暂缓判断并留痕。
- 暂定：从一个手动指定个股、一组试验依据和一轮历史回放开始，首轮优先体验大盘、板块、个股的研究顺序，可沿用日线、盘后、中期趋势的起点；对象、时点、观察周期、回放长度和依据范围均可根据原型反馈调整。
- 待原型确定：产品形态、因子与其他依据的取舍、各层方法的分工与组合、上下层是否构成否决条件、情境识别及适用性复核方法、具体操作和规则、自动化程度，以及持续观察和发现池的承载方式。
- 每阶段保留 **输入与必要依据 → 解释并作出选择 → 操作并记录 → 查看反馈 → 重新判断并留痕**。可以通过历史回放或明确标记的模拟推进提前体验变化；回放中的每次选择只使用当时可知的信息。
- 研究记录复用当前可用方式，保留足以回看的输入、理由、方法及组合版本和后续判断。各阶段的完成依据用于判断流程与新增能力是否走通，方法及组合的效果仍需独立验证。

### 阶段总览

| 阶段 | 目标 | 可体验的闭环 |
| --- | --- | --- |
| 1. 完成一轮个股观察与复核 | 给定个股，分别研究大盘、相关板块与个股趋势，完成观察选择和后续重新判断 | 指定对象、时点与各层口径 → 大盘趋势 → 相关板块趋势 → 个股趋势 → 观察选择并记录 → 推进时间与三层复核 → 重新判断并回看 |
| 2. 比较依据或策略的替换方案 | 理解替换某层依据、研究方法或组合方式怎样影响观察理由与选择 | 接续已有三层研究 → 比较替换前后依据与方法 → 选择保留、调整或暂缓并记录 → 回放复核两套方案的三层依据与适用性 → 解释差异并留痕 |
| 3. 复用研究方法并接续记录 | 在新的给定研究任务中复用各层方法及组合，保留连续判断和版本关系 | 指定新一轮对象、时点与各层口径 → 检查三层方法适用性 → 复用或调整后判断 → 推进时间与三层复核 → 接续记录并回看 |

建议先走通一次包含大盘、相关板块与个股研究的完整观察任务，再用同一任务理解替换的作用，随后把已有方法用于新一轮研究；顺序与范围仍可依据原型反馈调整。内容大纲中的研究输入、三层依据解释与判断、情境与适用性、观察选择、时间复核和记录在首轮共同使用，方法替换在第二阶段加深，跨任务复用与连续记录在第三阶段加深。每轮新增或替换一项能力，都接入已有判断与复核链路体验；某项新能力所必需的输入与解释随它一起纳入。

### 阶段 1：完成一轮个股观察与复核

- **目标：** 围绕给定个股，分别研究大盘、相关板块与个股趋势，理解各层判断为什么支持、质疑或尚不足以支持观察选择，并根据后续反馈重新判断。
- **内容范围：** 承接内容大纲的六个方向，形成最小完整任务：明确对象、时点、问题、大盘参照、相关板块口径和各层观察周期，优先依次解释大盘、板块、个股的原始数据、派生因子和人工依据，各层形成结论或保留未知，检查情境与方法适用性，再组合判断并推进时间复核三层变化。保留各层趋势研究方法、本轮情境识别、依据组合和观察方法及版本，作为后续替换与复用的起点；具体选哪些依据及上下层如何约束选择留待原型确定。
- **体验闭环：** 指定个股、历史时点、各层口径与一组试验依据 → 研究大盘趋势 → 研究相关板块趋势 → 研究个股趋势，各层留下支持、反对、结论或未知及方法 → 选择观察、结束观察或暂缓判断，记录理由和后续关注点 → 推进时间复核三层依据与策略适用性 → 对照原理由选择是否继续观察或调整方法 → 保留新判断并回看两次依据和方法版本。
- **完成依据：** 能说明三层判断及本轮观察选择与仍未知的部分，能在后续时点复核三层依据与方法适用性后重新判断，并回看当时依据、方法和理由。资料不足也能留下可解释的未知与暂缓判断；首轮样本与方法范围根据体验调整，结论方向或最终涨跌不作为完成条件。
- **体验入口：** [阶段一逻辑原型](prototypes/stock-research-first/index.html)及[运行与体验说明](prototypes/stock-research-first/README.md)。原型使用下表指定对象的 2025 年三层真实历史行情及试验方法，按真实交易日推进，提供三层分别研究、结论或未知、观察选择、时间推进与三层复核、方法解释版本修订及两次判断回看；可自由操作或按场景分步演练。必要资料缺失的模拟单独标记，历史信息时点、成员关系及不复权输入的限制在入口说明。具体功能取舍尚待使用者体验，方法效果仍需独立验证。

### 阶段 2：比较依据或策略的替换方案

- **目标：** 理解替换某层依据、趋势研究或情境识别方法、观察策略及组合方式，对各层判断、组合理由、适用性和观察选择产生了什么影响。
- **内容范围：** 复用首轮完整链路，在同一对象与研究时点比较原方案和替换方案，探索各层判断和单项依据的贡献、冲突与缺失的处理，以及趋势研究、情境识别、依据组合和观察策略的分工。每次替换纳入该方案必要的输入与解释，再走完观察与三层复核；保留原方案和新版本，人工解释的部分仍明确记录。研究顺序和是否设置上下层否决条件作为组合取舍分别体验，不预先固定。
- **体验闭环：** 接续一轮已记录的三层研究及原方法 → 选择一项待比较的依据、策略或组合方式并说明替换假设 → 在同一时点解释两套方案的各层判断、理由与选择 → 决定本轮保留、调整或暂缓采用并记录 → 分别推进时间复核两套方案的三层依据与策略适用性 → 对照判断与适用条件差异，留下比较发现。
- **完成依据：** 能解释替换前后选择是否变化、变化来自哪里，以及其余部分能否复用；能追溯两套方法和判断，保留支持采用、暂缓或仍待探索的理由。比较结果用于推敲功能与方法，不能以事后较好结果代替当时可作出的选择。

### 阶段 3：复用研究方法并接续记录

- **目标：** 将已形成的各层研究方法及组合用于另一轮给定任务，检查复用需要什么条件，并持续回看对象与方法的变化。
- **内容范围：** 接续前两阶段的方法与版本，在同一个股的新时点或另一手动指定个股上重新研究，说明本轮大盘参照、相关板块口径和各层观察周期，检查三层情境和必要依据是否支持复用、调整或暂缓使用。接续该对象的三层研究与观察记录，区分对象不再值得观察、方法可能不再适用和资料不足；记录向发现池积累的方向沿用来源大纲，具体承载方式通过原型体验决定。本地第三阶段仍围绕给定任务复用，范围内发现、集合比较和板块独立跟踪接续来源大纲阶段 2。
- **体验闭环：** 指定新一轮个股、时点、各层口径与已有方法 → 查看三层必要依据并检查策略适用性 → 选择复用、调整或暂缓使用方法，各层形成结论或保留未知，再形成观察选择并记录 → 推进时间复核三层依据与策略适用性 → 重新判断是否继续观察及是否调整方法 → 接续研究记录，回看原版本、新版本与各次选择。
- **完成依据：** 能把已有方法用于新任务并说明适用或调整理由，能走完新一轮判断与复核，能沿对象记录回看方法变化且保留原判断。体验后能够指出持续观察与记录组织中已确定的取舍和仍待探索的问题；记录方式与产品形态保持可调整。

## 原型与文档如何配合

- 规划文档保留探索目标、内容范围、体验闭环、完成依据和待验证问题；因子选择、计算与组合方式、具体操作及规则在原型中推敲。阶段划分仍是探索建议。
- 每次原型围绕一个明确的观察任务提供可操作样例、反馈与回看记录。新增或替换能力时，体验它对理由、选择和后续复核的帮助；临时方法与规则标为试验假设，体验后的取舍再形成需求。
- 真实历史、最新可用资料和模拟演示分别标明；按研究时点推进，只使用当时可知的信息。回放和模拟可以支持流程与交互判断，不能冒充方法有效性的独立验证。
- 从首轮起保留对象、三层当时依据、结论或未知、观察选择、方法及组合版本和反馈，调整后保留新旧区别，历史判断继续关联原版本。记录复用已有方式，逐步沉淀能够再次使用的策略方法。
- 形成结论时记录对应原型、体验发现和已确定的取舍，再同步相关需求与术语；未验证项继续保留。方法有效性和组合效果的验证按来源研究大纲接续，探索样本的比较发现分别记录。
- 工程能力随闭环按需增加，遵守现有分层架构、数据契约和图表规范；具体业务边界以原型形成的需要为依据。

下一步建议从阶段 1 的“一个给定个股与历史时点，大盘趋势 → 相关板块趋势 → 个股趋势 → 观察选择 → 时间推进与三层复核”开始，先说明各层参照、口径和观察周期，分别留下依据、结论或未知及方法，再体验组合判断、策略适用性检查与时间反馈。通过原型推敲首轮依据范围、研究顺序、各层方法分工和组合取舍，再决定记录承载方式；最终产品形态保持开放。
