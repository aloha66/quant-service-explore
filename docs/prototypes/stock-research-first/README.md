新记录只在内存中，刷新会清空；原判断原文不会随重置清空。导出 Markdown 包含首次原判断、本轮已保存的依据、口径、改变条件和回看；未保存草稿不导出。保存前工具只能选择历史时点及以前的日期；展开后续后可以比较后续日期，但不能改写已锁定的依据。没有重新取数、接入数据库、增加依赖或生成研究结论。

## 第二轮怎么体验

1. 在“区间高低”切换整段 60 日 / 最近 20 日，开关高低点标记。核对区间、最高最低日期，再决定是否加入依据。
2. 在“观察位”查看两个候选的出处；也可点图或用键盘左右键后按 Enter 选日期，再选择最高 / 最低 / 收盘作为参照。参照线不会随区间切换自动替换。
3. 在“改变理解”比较盘中高低价与收盘价，并自己写下观察期限、可观察变化和要重审的理解。可以明确记录暂时说不出以及缺什么信息。
4. 在“量能比较”切换前一日 / 此前 5 日 / 此前 20 日均量，查看基准日期和倍数，再加入依据。均量不含当天，历史不足不缩短样本。
5. 保存四栏与至少一条依据，展开后续 20 日，选择后续日期对照。先记录事实与条件是否可检验，再逐项评价四项工具的帮助。可继续追加理解、导出或重置本轮练习。

所有候选与参数都是试验假设；极值没有被直接认定为有效支撑压力，没有自动趋势判断或突破信号。若需验证盲看表达改善，再选择未看过后续的 2025 年案例，无合适案例才退到 2024 年。

## 沿用的首次案例

- 沈阳机床（000410.SZ），历史时点为 **2025-08-08 收盘**。
- 观察窗口为 2025-05-16 起的 60 个交易日；一次性延伸 20 个交易日。
- 优先在 2025 年找案例，本次无需回看 2024 年。
- 观察阶段存在区间整理、修复能否持续等不同理解空间；这是制作者的选样假设，页面不预填解释，不给出推荐。
- 区间日收盘变动没有超过 5%，不靠极端单日行情构造揭晓。曾排除波动更极端的候选，也排除前复权快照已受后续分红影响的候选。
- 该公司 2025 年有持续推进的资产重组事项，见[发行人披露](https://epaper.cs.com.cn/zgzqb/html/2025-09/30/nw.D110000zgzqb_20250930_3-B021.htm)；不能声称是“无事件”样本。当前区间没有停牌/复权跳变，是否熟悉结果、是否适合首次研究仍待体验。
- 首次三栏必填、60/20 的跨度和一次揭晓，都是临时选择；本轮增加改变条件与依据记录，其效果仍待体验。

## 数据证据与边界

`case.json` 保存本轮固定快照；`index.html` 内嵌同一份数据，因此不依赖网络、框架、CDN 或后台。`sources/` 保存原始响应，保留可回读证据，不作为页面的实时信息入口。

| 项目 | 本轮处理 |
| --- | --- |
| 来源 | 腾讯财经 `fqkline/get`，真实上游未知；完整请求、采集时间、原始响应 SHA-256 见 `case.json` |
| 字段映射 | 日线数组为 `[trade_date, open, close, high, low, volume]`，数值字符串转为有限数值 |
| 价格 | 固定供应商前复权快照。80 根展示行情及前一根昨收种子，OHLC 与不复权响应逐项一致；不引入应用侧复权引擎 |
| 量额 | 源成交量为手，界面只除以 10000 显示万手。源缺成交额，`amount=null`，不以价格乘量伪造 |
| 换手率 | 没有经过验证的历史流通股本，`turnover_rate=null` |
| 连续性与昨收 | 深交所 2025 年 5—9 月完整官方月历，逐月核对自然日完整和交易标记；本窗口及前收种子的交易日连续。昨收取同快照前一官方交易日 close |
| 缺失呈现 | 保留 11 行行情明细及字段顺序；缺失项为 `--`。价格两位、红涨绿跌、小额阈值与万手/亿单位沿用现行规范 |
| 信息边界 | 揭晓前，蜡烛、成交量、两轴范围、时间刻度、hover、可访问表格和导出只用前 60 根。揭晓后只延伸同一张图 |
| 历史局限 | 这是后来取得的历史数据，不是供应商逐日发布的档案，不能证明无事后数据修订，不是正式 PIT 数据集 |

这份静态文件内含完整揭晓数据；源代码和开发者工具不是保密边界。本轮固定标记该案例已看过后续，刷新不会让它变成首次盲看。重新体验只清空本轮内存记录。

## 实现与后续记录

`ResearchSession` 是无 DOM/IO 的内存状态转换模块；`ChartEvidence` 只计算区间事实和量能基准，不推断支撑压力。页面是可丢弃外壳。未接入业务层、账户、数据库、Proto 或服务接口，没有新增运行依赖或测试套件。
