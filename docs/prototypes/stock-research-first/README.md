# 阶段一：个股观察与复核逻辑原型

对应[探索路线图的阶段一](../../2026-10-03-stock-research-observation-roadmap.md#阶段-1完成一轮个股观察与复核)。这是可丢弃原型，用来回答：三层分别研究能否支持一个说得清的观察选择，并在推进时间后复核原理由？方法、周期、研究顺序和交互都是试验假设，尚未据此确定正式需求或证明方法有效。

## 打开

直接双击 [index.html](index.html)。页面自带全部数据和脚本，无须安装依赖、联网或启动后端；研究状态只在内存中，刷新或重新开始会清空。需要保留时点击“导出本轮记录 JSON”。

也可以在仓库根目录运行：

```bash
python3 -m http.server 8897 --bind 127.0.0.1 --directory docs/prototypes/stock-research-first
```

打开 <http://127.0.0.1:8897/>。端口占用时换一个端口。

## 先体验观察与复核

默认对象为新易盛，研究日为 2025-03-03，参照沪深300与申万一级通信指数。日期、对象和三层观察周期可以自行修改。按“观察与复核”场景的当前步骤按钮走一轮，或使用正文控件自由研究：

1. 指定对象、历史日期、问题、三层观察周期；说明必要资料及当时可得日期。
2. 依次查看大盘、相关板块和个股。每层分别保存支持、质疑、未知、情境和方法适用性；未知也能提交，但需要解释原因。
3. 人工选择观察、继续观察、结束观察或暂缓判断，留下理由、判断范围和下次关注点。首次不能“继续观察”；结束后需重新“观察”。三层研究顺序不意味着上层自动否决。
4. 保存本时点选择后，按真实交易日推进 1、5、10 或 20 日，比较三层依据，再重新提交三层研究及观察选择。
5. 回看两次记录、理由与当时方法版本。方法解释另存新版本后，相关草稿需重新提交，旧快照不会覆盖。

另有“资料不足与暂缓”和“方法修订与回看”场景。前者明确模拟必要公告资料缺失，真实行情不变；后者仅修订方法解释与版本，不实施阶段二的替换效果比较。引导中的人工解释只是演练样例，不是基于涨跌给出的自动建议。

## 真实行情与输入边界

- 31 个标的、10,007 根日线：沪深300、路线图指定的 10 个申万一级行业指数与 20 只个股。数据覆盖 2024-09-02 至 2025-12-31；2024 年最多 80 个交易日供预热，2025 年有 243 个大盘交易日。
- 沪深300和个股来自腾讯历史日线；板块来自[申万官方历史接口](https://www.swsresearch.com/institute-sw/api/index_publish/trend/?swindexcode=801770&period=DAY)。完整来源 URL、采集时间、原始响应 SHA256、覆盖与单位证据在 [history.json](data/history.json) 和 [unit-evidence.json](data/unit-evidence.json) 中。
- 申万官方量额单位为亿股、亿元，分别转换为标准的手、人民币元；腾讯成交量手单位据官方图表脚本验证。页面仅将量除以 10,000 显示万手，额除以 100,000,000 显示亿。不以价格乘成交量补成交额。
- 中芯国际在 2025-09-01 至 2025-09-08 缺少 6 个大盘交易日行情，原因未核实。保留缺口，不伪造 bar、不回填旧价；受影响的窗口指标保留未知。
- 股票为**不复权原始历史价格的试验输入**，不是已经验收的前复权研究系列。新易盛 2025-05-28、比亚迪 2025-07-29 等窗口存在明显原始价格跳变；公司行动未核实，跨此类窗口不能把价变当成纯市场表现或总收益。所有价变指标均标明这一限制。
- 数据在 2026-10-03 采集，是现在下载的真实历史快照；未证明供应商历史发布和修订的精确信息时点。页面只按研究日截断行情及指标，禁止加入可得日期晚于研究日的人工资料，但不能据此声称严格历史 PIT 已验收。
- 板块映射是路线图给定研究参照，2025 年真实成员归属与参与情况未知。基本面、公告、事件与历史公司行动未完整提供，默认问题限定为价格结构的有限观察；如果本轮依赖某项资料，需要补充或标为必要缺失，并暂缓或解释怎样收窄范围。
- 昨收、历史流通股本及换手率口径未核实，保留空值；腾讯未提供成交额。11 行行情明细保持字段顺序，缺失显示 `--`，不补零。

图表提供日线、MA5/10/20（可选30/60/120）、成交量、BOLL20/2、MACD12/26/9及RSI6/14/24，遵循[图表规范](../../2026-09-06-kline-display-and-indicators-spec.md)的计算与显示口径。默认视窗为研究日向前4个日历月；可浏览范围限于本原型实际取得的历史，不宣称两年行情或分钟数据已就绪。递推指标固定从捕获序列首日初始化，未知缺口后保持未就绪；图表范围变化不重新播种。回放末价只使用研究时点已知的末价。

## 记录与后续取舍

每次保存包含 `user_id=admin`、对象及口径、研究时点、三层已知行情和因子、人工依据及结论或未知、选择理由、关注点、必要资料、六项方法版本及前次反馈。导出只包含已保存研究时点及此前的数据，不附带后续行情。

“体验发现”另行记录流程与交互问题，标为待使用者验证。此次浏览器操作走通三个引导场景及自由操作，并检查了桌面与390px窄屏；这说明原型可运行，不代表使用者已认可功能取舍，也不代表方法有效。等待实际体验后再把确定的决定同步到正式需求和领域文档。

## 修改与重建

所有源文件位于本目录；只有 `index.html` 是需要交给体验者的单文件成品。

- `prototype_model.js`：无 DOM 的纯状态模型。
- `prototype_chart.js`、`prototype_ui.js`、`index.template.html`：可丢弃页面外壳。
- `data/history.json`、`data/raw/`：真实行情包与33份原始响应留档。原始供应商响应可能包含当下报价或更长历史，仅供来源回读；这些附带内容不进入单文件原型的研究输入。
- `fetch_data.py`：用系统 Python 与 curl 重取这批公开历史数据，无新增依赖。
- `build_html.py`：将数据、模型和页面内联为 `index.html`。

```bash
python3 docs/prototypes/stock-research-first/build_html.py
```

需要主动更新样本时先运行 `fetch_data.py`，再重建 HTML；重取会改变此次快照版本，不会恢复用户的内存记录。原型未接入生产服务、数据库、持久化或自动交易，也未改动生成代码。
