# 本轮原型的界面假设

仅作用于 `index.html`，不是正式产品设计系统。模式为 Operate；以简报的研究任务为依据，直接做一轮可操作的研究，不开展视觉方案评选。

首屏用图表和文字判断并排，宽屏主要空间给行情；窄屏先看图，再写判断。保存后将输入区替换为不可修改的原文。揭晓在原图上延伸，原文仍在旁边；下方两栏分别记录案例回看和原型发现。

图表留白只表示未揭晓，不编码未来价格。状态以“未保存、已锁定、已揭晓、已保存”表达，所有临时试验规则放在简短说明中。不用评分、建议、收益或成败颜色解释结果。

颜色：页面 `#f6f7f5`、图面 `#ffffff`、正文 `#202c2b`、次要文字 `#5f6c69`、操作色 `#245a50`、边界 `#dce2de`。行情上涨 `#c23d40`，下跌 `#24825e`。中文系统字体，正文 15px，输入 14px，数字为等宽数字。控件至少 44px，显式键盘焦点，无动画。

交互与布局是否有助于研究，仍以用户实际体验为准。

## 第二轮追加的界面假设

沿用 Operate 模式与现有视觉，不做视觉方案重选。图表前的四项标签按“区间高低 → 观察位 → 改变理解 → 量能比较”逐项体验，帮助正文按当前项展开。右侧保留首次原判断的只读入口，新增依据清单和本轮理解练习；窄屏按图表、工具、记录的顺序排列。

事实带区间、日期、字段和快照出处。候选参照用中性虚线，不用红绿暗示交易方向；行情红绿仍只表达开收关系。图上高低标记与参照线可同时显示，文案区分价格事实、待检验解释和本轮个人表达。选中日期有固定竖线，临时悬停不改变它。初始不显示遮挡标记的明细浮层，查看动作仍显示原有 11 行明细。

保存时冻结依据与口径，继续切换工具只改变图表比较；本轮理解不冒充首次盲看判断。四项帮助分别记录体验反馈。上述呈现、默认值与填写要求均为试验，等待使用者验证。
