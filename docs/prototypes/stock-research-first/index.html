候选观察位，从哪里来？

试验：只用所选历史区间的最高与最低作两个候选入口，没有自动识别“有效支撑 / 压力”。也可以点图中任意日期，自选一个价位。

    支撑、压力、突破，分别在说什么？

    支撑 / 压力是待检验的解释：关注某个区域附近，下跌是否停住、上涨是否受阻。曾经出现过这样的反应，不保证再次出现；影线数量不能单独说明支撑强弱。

    突破需要参照和口径：先说越过哪里，再区分“盘中曾超过”和“收盘高于”。这里用一条精确价格线方便比较，并未确定区域宽度、持续天数或有效突破规则。

    概念出处：Fidelity：支撑与压力。本页候选选择方法为试验假设。

    什么变化，会让我重新考虑？

    先选一个有出处的观察位，再比较同一天的盘中高低价与收盘价。相同价格参照，观察口径不同，描述也可能不同。

    在记录区按自己的话补完：“在什么时间内，出现什么可观察变化，我会重新考虑当前理解的哪一部分？”也可以明确写还缺什么信息，暂时无法提出条件。

    说“放量”之前，先选比较对象。

    均量不含当天；历史不足时显示缺口，不缩短样本。倍数只表示成交数量的相对变化，放量也可能伴随下跌，不能直接推断接下来上涨。

    量柱为什么不能直接代表买入力量？

    每笔成交都有买方和卖方，本快照未提供主动买卖分类。量柱颜色仅按收盘与开盘比较。研究解释仍需自己结合价格变化提出。

    概念出处：Schwab：成交量与比较基准。1 / 5 / 20 日只是本轮可比较的试验选项，没有设置信号阈值。
