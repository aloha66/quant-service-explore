# 反向接续：实际工程检查

日期：2026-09-27。对象：[index.html](index.html)，版本 `stock-sector-v4`。

**这里记录主代理浏览器检查与子代理静态/界面审查，不是使用者体验，也不是阶段三完成、概念掌握、盲看或方法有效性证据。** 使用者原文只在 [experience-2026-09-27-round-3.md](experience-2026-09-27-round-3.md)；代理输入一律标明“浏览器检查”或“手机浏览器检查”，交接前刷新清空。

## 本轮原型范围

- 接续上轮保存的贵州茅台原话，主动回看主要消费指数。个股原话来自正向联动；两者后续均已看过，固定标识这一事实，不再让熟悉程度退回不确定。
- 选择板块对个股原理解的影响，分别写影响理由与板块自身理解，一次锁定；条件选填。
- 按需手选同起点对照的起止日期，仅呈现走势与端点事实；日线单日核对日期独立。没有新增独立分歧样本、自动趋势、相似度、收敛或交易判断。
- 展开后续后日线定位最后日；对照保留所选区间，允许手动查看后续。两类原话与保存时依据不随操作重算。
- 回看分别记录后来事实与表达/依据质量，发现选填，追加另存，导出保留既有完整原文。

## 浏览器实际覆盖

使用 Codex 内嵌 Chromium 及已有本机静态预览 `127.0.0.1:8766`。主代理先查看 v3，再检查 v4：桌面 1440×1000、手机 390×844；结束恢复默认视口。恢复后的默认视口宽 1323px 也检查首屏。没有调用外部页面或传输研究文本。

| 检查 | 实际结果 |
| --- | --- |
| 初始状态 | 个股原话与 60 根日线，板块入口未点击；当前新记录为空；两者后续已知，成员身份未知 |
| 主动板块入口 | 打开后允许对象切换与按需对照，出现两类记录字段；手机自动聚焦图题 |

| 对照区间 | 手选 2025-06-16 至 06-23 后显示指数 -1.05%、个股前复权 -0.17%；这些是端点收盘变化，不概括段内全部走势 |

| 导出 | 桌面与手机都实际点击下载入口，并核对只读导出文本；含新版本、既有原时间和旧熟悉程度、两者文字、已知后续、新信息边界及所选区间。没有核验下载在磁盘的落点或重开下载文件 |
| 重做 | 取消保留回看；确认清空仅本轮新记录，恢复个股入口、60 根与默认对照；固定“后续已看过”事实不变 |
| 手机完整路径 | 主动回看 → 选择“仍无法判断” → 两类文字保存 → 展开 → 跳转回看 → 保存事实/质量 → 选填发现 → 导出 |
