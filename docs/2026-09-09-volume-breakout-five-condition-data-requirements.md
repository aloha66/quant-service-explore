# 放量突破与趋势启动：五项条件、检测数据与可交易性

> 编写日期：2026-09-09；更新日期：2026-09-12。适用讨论：A 股个股的日线／波段趋势判断，并补充盘中观察及可交易性检查所需数据。
>
> 目的：丰富“突破平台、明显放量、多龙头领涨、中长期均线向上、与大盘共振”五点，逐项说明要看什么、取什么数据、怎样计算、何时才能判断，以及哪些情况容易误判；另设可交易性检查，判断指定交易计划在观察时刻的执行条件。
>
> 本文是数据与判断口径说明。公式和参数用于表达可检测的条件；示例阈值尚未经过本项目行情样本或回测验证，不代表已验证的交易策略。

> 标准输入：[统一行情数据契约](2026-09-12-market-data-contract.md)。本次只调整来源依赖与单位说明，保留五项条件、阈值示例、公式和可交易性边界；QMT 作为候选来源的映射见[接入规范](2026-09-12-qmt-source-adapter-spec.md)。

## 0. 五点分别回答什么问题

| 条件 | 核心问题 | 不能省略的判断层次 |
| --- | --- | --- |
| 1. 价格突破前期平台／压力位 | 原有价格约束是否被突破？ | 先存在平台，再检测越过压力位，最后检查收盘质量与后续站稳情况。 |
| 2. 成交量明显放大 | 突破时的交易参与是否显著增加？ | 比较历史基准，同时检查成交额、量价配合及放量持续性。 |
| 3. 同一板块多龙头股领涨 | 这是个股独立上涨，还是同一方向的集体走强？ | 先界定板块和龙头，再检查多龙头同步、普通成员跟随及板块整体强度。 |
| 4. 中长期均线向上 | 价格是否有持续向上的趋势背景？ | 分开检测均线方向、持续性、相互排列以及股价偏离程度。 |
| 5. 与大盘同频共振 | 个股上涨是否获得市场环境支持？ | 对齐时间，检查指数方向、市场广度、成交活跃度及个股—板块—大盘的相对强弱。 |

五点相互补充，但其中的信息存在重叠。例如“股价强于板块”和“板块强于大盘”都使用收益率，不能据此假定五项是五个相互独立的证据。检测时先保留各项原始值与结论，不在本文中预设总分权重。

突破质量已在第 1、2 点展开。第 6 节另行检查可交易性，分别保留“形态条件”和“当前执行条件”的结果。例如形态可以满足，但指定数量在限定价格内缺少足够对手盘；这不应倒改历史形态判断。

### 0.1 原始数据、计算结果和参考数据的区别

- **原始证据与标准行情**：供应商原字段、值、单位、价格口径单独保留；本稿公式读取适配后、符合统一契约的 OHLC、volume、amount 和时间，不能直接混算各来源原始值。
- **基础／关系数据**：证券身份、交易状态、板块成员、流通股本、交易日历等。它们决定统计对象和分母，并不都包含在 K 线里。
- **派生指标**：平台上沿、放量倍数、换手率、均线斜率、龙头排名、上涨比例、相对强弱等，需要明确计算，不能假定是上游的直接字段。
- **增强数据**：分钟线、逐笔成交、盘口、公告、产业地位资料等。只有在判断使用这些信息时才成为必要输入；日线五项检测不天然要求全部具备。

### 0.2 共同时间与价格口径

1. `t` 表示被判断的目标交易日，`τ` 表示盘中的观察时刻。`O/H/L/C/V/A` 分别表示标准开盘价、最高价、最低价、收盘价、成交量、成交额；股票 V 固定手、A 固定人民币元。换手率以 `V * 100` 转股后除以当日有效流通股本；涉及计划数量 Q 或盘口股数比较时，也先将 K 线量转股。不得使用 UI 的万手、亿或格式化百分数字符串参与计算。
2. 示例公式中的 `t-k` 默认指交易所日历上的第 k 个此前交易日。简式假定窗口内有完整有效行情。若有认可的停牌空槽，应另行说明取有效 bar 的规则，并记录实际起止日期、有效数量和停牌间隔；未知缺口不能通过向前多取几天来掩盖。
3. 平台、历史均量和事前龙头名单的基准截至 `t-1`；当日日线均线可以包含 `C(t)`。盘中使用的当前价和均线为临时值，不能称为当日最终收盘信号。
4. 趋势价格沿用统一契约的前复权研究序列，按数据集选择已验收来源，统一系列快照。复权基准发生变化时，不能把新旧价格直接拼接。盘中原始 Tick、实际涨跌停价格和研究价格须分别标识；比较前应证明处于一致价格基准。
5. 本文的区间表现 `R_X(k,t)=C_X(t)/C_X(t-k)-1` 是指定价格序列的变化率；不是自动包含分红再投资的总收益率。计算跨标的相对表现须声明可比口径，不能混用价格指数、全收益指数和未说明的复权收益。
6. 百分比公式的价格或均值分母须为正，成交量／成交额比率的基准须大于零；否则结果为“无法判断”。远期前复权价格异常或非正时，不能继续机械计算百分比。零振幅 K 线的影线比例同样无法定义。
7. 日线最终判断须等输入日线达到既有数据策略规定的完成与质量要求，不能仅因时间到达 15:00 就视为完整。比较个股、板块和指数时，交易时段及盘后数据纳入范围须一致或明确区分。
8. 重现历史当时的判断时，须锁定当时可取得的行情、复权快照和元数据版本。使用今天修订后的完整历史进行分析，应标记为“修订后历史研究”，不能宣称重现了当时已知的信号。没有当时版本或可信重建证据时，不能虚构历史可得性。

项目数据与均线口径分别见 [K 线数据获取、入库与补偿策略](/Users/aloha66/code/quant-service-explore/docs/2026-08-31-kline-data-ingestion-storage-policy.md) 和 [K 线展示与指标说明](/Users/aloha66/code/quant-service-explore/docs/2026-09-06-kline-display-and-indicators-spec.md)。本文新增的是检测需求，不代表现有系统已经实现这些指标。

## 1. 价格突破前期平台／压力位

### 1.1 丰富后的含义

这一点应拆成三个问题：此前是否形成整理结构；价格是否越过预先识别的压力区域；越过后能否留在其上方。

“过去 N 日新高”只能回答价格是否超过历史高点。持续单边上涨的股票也会不断创 N 日新高，因此还需要平台持续时间、横向波动范围、价格漂移、反复接近上沿等证据。压力更适合表示为区域，不能把一分钱的越过一律解释成有效突破。

### 1.2 需要采集什么数据

| 数据 | 粒度／范围 | 用于判断什么 | 必要程度与注意点 |
| --- | --- | --- | --- |
| 个股 `O/H/L/C`、行情时间及完成状态 | 日线；目标日前至少覆盖选定平台窗口 | 上下沿、区间形状、突破位置、K 线收盘质量 | 必需。平台窗口排除突破日。 |
| 更长区间的 `H/L/C` | 如此前 120～250 个交易日 | 平台上方是否还有较近的历史高点／更大级别压力 | 增强。记录最近上方压力与其距离，不把它直接解释成实际套牢盘成本。 |
| 历史收盘价及前收基准 | 覆盖波动计算的预热区间 | 日间跳空、真实波幅、正常噪声大小 | 使用 ATR 类容差时必需；相邻价格必须同一基准。 |
| 交易日历、停复牌、上市日期 | 平台期间和目标日 | 整理是实际交易形成，还是停牌／新股短历史造成 | 必需。连续停牌不能累计为横盘整理天数。 |
| 复权快照及除权事件信息 | 覆盖所用价格区间 | 是否因除权或历史价格修订产生假突破 | 必需。原始除权事件是否直接参与计算取决于数据契约。 |
| 分钟 `O/H/L/C`、时间与完成状态 | 突破当日；需要时延伸到后续交易日 | 首次突破时刻、站上压力位的时长、回落／重新突破次数 | 盘中增强；只有日线无法恢复先突破还是先下跌的路径。 |
| 成交量、成交额 | 与平台和突破 K 线同周期 | 平台内缩量及突破时放量 | 与第 2 点共用。 |

### 1.3 需要计算并检测什么

以此前 `N` 日为候选平台窗口，先计算下列基线；`N=20/40/60` 是可比较的窗口示例。

```text
平台上沿 P = max(H(t-N), ..., H(t-1))
平台下沿 B = min(L(t-N), ..., L(t-1))
平台宽度 = P / B - 1
收盘突破幅度 = C(t) / P - 1
盘中最大越过幅度 = H(t) / P - 1
收盘位置 = (C(t) - L(t)) / (H(t) - L(t))
上影线占比 = [H(t) - max(O(t), C(t))] / (H(t) - L(t))
```

| 检测项 | 需要的计算或观察 | 判断目的 |
| --- | --- | --- |
| 平台长度 | 起止日、有效交易 bar 数、实际跨越日历天数 | 排除只有几根 K 线的偶然停顿及停牌造成的假整理。 |
| 平台宽度 | 上述宽度，并结合个股通常波动水平比较 | 识别横向整理；同一宽度阈值对高波动和低波动股票未必适用。 |
| 平台整体漂移 | 对窗口内收盘价按时间做线性回归；保存斜率，并除以窗口平均收盘价得到每日相对漂移 | 区别横盘、缓慢上倾整理和明显单边上涨。绝对斜率大不支持“横盘平台”。 |
| 上沿测试次数 | 历史高点落入 `P±ε` 的独立接近事件数及日期 | 多次靠近同一区域提供压力区域证据。相邻数日贴着上沿应合并为一次，须预定事件间隔。 |
| 整理收敛程度 | 平台后半段与前半段的平均日振幅／真实波幅之比 | 补充判断波动是否逐步收窄，而不是持续剧烈摆动。 |
| 突破幅度 | 收盘超过上沿的比例、超过上沿的绝对距离／此前 ATR | 判断越过距离是否超过通常噪声。阈值须基于突破前波动确定。 |
| 突破收盘质量 | 收盘位置、实体方向、实体占比、上影线占比 | 区分收在高位和冲高回落。放量也不能弥补收盘已回到平台内的事实。 |
| 高开与跳空缺口 | `O(t)>C(t-1)` 表示高开，`O(t)>P` 表示开在平台上方；`L(t)>H(t-1)` 才表示全日仍未回补的向上价格缺口 | 三项分别检测；只有开盘高于前日最高价不能证明缺口保持到收盘。盘中何时回补需要分钟路径。 |
| 盘中保持情况 | 已完成分钟 bar 收盘位于 `P` 之上的比例、最长连续保持时间、回落次数 | 区别瞬间越线和持续站稳；日线数据不能给出此结论。 |
| 上方空间 | 高于当前价格的更长周期压力区域与当前价格的距离 | 识别刚突破小平台就接近更大压力的情况。历史高点只能作为参考压力。 |
| 后续保持／回踩 | 突破后第 1、2、3 日收盘是否保持在原 `P` 附近或其上；回踩时量能 | 跟踪突破是否延续，属于之后才可获得的新证据。 |

容差 `ε` 是价格距离，可以取 `P×预设百分比`，或 `ATR(t-1)×预设倍数`；正式比较时固定一种定义及参数。不能在看到结果后挑选最容易通过的容差。

若使用 ATR，真实波幅取 `max(H-L, abs(H-C_prev), abs(L-C_prev))`，其中 `C_prev` 为同一研究序列的前一有效收盘价。ATR 可按 Wilder 平滑：先以固定锚点后的首 14 个有效真实波幅均值播种，再按 `(前值×13+当前TR)/14` 递推；未知缺口及输入修订后的恢复需固定规则。不能把滚动算术均值和 Wilder ATR 混用。[ATR 基础定义](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)

### 1.4 建议的判断顺序与示例

1. 在此前数据上识别候选平台，保存窗口、上下沿、宽度、漂移和独立测试次数。多个窗口可分别输出；若只选一个，预定选择规则，不能事后选表现最好的窗口。
2. 将当日价格与该平台比较，分别记录“盘中越过”“收盘越过”“超过容差”。
3. 结合收盘位置、影线和第 2 点量能，描述突破质量。
4. 首次触发时固定原平台边界。后续日继续用这个边界观察站稳与回踩，避免滚动更新高点后把原来的判断对象换掉。

例如：已确认的平台上沿为 10.00 元，今日最高 10.50 元、最低 9.90 元、收盘 10.30 元，则收盘突破幅度为 3%，收盘位置约 66.7%。若收盘改为 9.95 元，即使盘中曾上涨到 10.50 元，也只能记录“盘中越过后收回平台内”。示例仅演示计算。

**应保留的结果**：平台是否成立及原因、平台起止日、上下沿、宽度、漂移、测试次数、首次触发时间、收盘突破幅度、收盘位置、影线比例、站稳状态、后续回踩状态及各自观察时间。

### 1.5 容易误判的情况

- 单边上涨中新高被误认成平台突破；异常尖刺抬高平台上沿。若改用高点聚类或分位数，须作为另一种压力识别方法记录，不能暗中替换上述最高价定义。
- 除权、新旧复权快照混用、数据漏行或错误补值制造虚假的平台与跳空。
- 未经未来数日确认的局部高点，被提前当作已知摆动高点。使用需要右侧 K 线的拐点算法时，必须记录实际确认日期。
- 用日线最高价推断发生过可成交的突破、维持了多久或完成过回踩；一根 OHLC 无法给出完整路径。
- 突破后第 3 日才获得的“连续站稳”证据，被回填成突破当日已经满足的条件。

## 2. 成交量明显放大

### 2.1 丰富后的含义

“明显放大”是相对自身过去可比交易活动而言。至少需要回答：相对什么基准放大、放大多少、成交金额是否足够、价格是否保持强势，以及放量是否只集中在短暂冲高或特殊交易时段。

成交量体现交易活跃程度，不能单凭放量推断交易者身份或“主力净买入”。量能变化可辅助观察压力突破，但本文的放量倍数和阈值是独立设计，并非直接采用 Volume Oscillator 公式。[成交量变化与突破的基础说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/volume-oscillator)

### 2.2 需要采集什么数据

| 数据 | 粒度／范围 | 用途 | 必要程度与注意点 |
| --- | --- | --- | --- |
| 个股成交量 `V` | 当日及此前至少 20 日，增强可覆盖 60 日以上 | 均量、放量倍数、历史分位、缩量整理 | 必需；基准不包含当前日。单位、成交范围及复权是否影响数量必须核实。 |
| 个股成交额 `A` | 与成交量同周期、同时段 | 金额放大、最低流动性、活跃度排名 | 必需；不要用前复权收盘价乘成交量替代真实成交额。 |
| 当期有效流通股本 | 日级有效记录、发布／可得时间 | 流通股换手率、股本变化后的可比性 | 使用换手率时必需；当前股本不能替代历史股本。 |
| 个股 `O/H/L/C` | 与量能完全对齐 | 量价配合、冲高回落、长上影及波幅 | 必需。 |
| 停复牌、除权／股本变动、交易日与交易时段 | 覆盖基准窗口和目标日 | 排除不可比基准与特殊事件 | 必需；停牌不当作正常零量交易日稀释均量。 |
| 历史及当日分钟成交量／额 | 相同分钟槽，基准覆盖多个完整可比交易日 | 盘中同时刻累计放量、局部放量、成交时段分布 | 盘中检测必需。仅最新 Tick 快照不足以恢复历史比较基准。 |
| 逐笔成交、竞价／盘后成交分类 | 突破前后 | 更精细地识别大额成交、主动方向及特殊时段影响 | 增强；须有相应权限和明确定义，不能从日线凭空推导。 |

### 2.3 日线应检测的指标

```text
历史均量 VMA_N_prev = mean(V(t-N), ..., V(t-1))
日成交量倍数 RVOL_N = V(t) / VMA_N_prev
日成交额倍数 RAMT_N = A(t) / mean(A(t-N), ..., A(t-1))
流通股换手率 = 当日实际成交股数 / 当期有效流通股本
整理缩量比 = mean(V(t-5), ..., V(t-1)) / mean(V(t-20), ..., V(t-1))
```

换手率以上式小数保存时，展示百分数再乘 100；股票标准成交量已经固定为手，此处以 `V * 100` 得到实际成交股数。上游单位转换在适配层完成，不能在检测中再次按来源缩放。来源数量不符合实际成交量语义时不得进入本标准配置。流通股本不可得时本指标为“无法判断”，不能回退总股本后仍称“流通股换手率”。

| 检测项 | 检测数据／计算 | 需要回答的问题 |
| --- | --- | --- |
| 短期与常态放量 | `RVOL_5`、`RVOL_20` | 是相对最近极度缩量突然放大，还是相对较长时间常态也显著放大？ |
| 成交额同步变化 | `RAMT_20` 与当日绝对成交额 | 成交数量增加是否伴随有意义的资金成交规模？价格上涨本身也会影响成交额，应与量分别解释。 |
| 历史异常程度 | 当前量在此前 60 日成交量分布中的百分位；必要时同时给出相对历史中位数的倍数 | 均值是否被少数极端放量日拉高，当前量是否位于自身历史高位？ |
| 整理期缩量 | 上述整理缩量比，或平台前后半段均量之比 | 突破前是否有交易活动收缩的过程？它是增强证据，不预设为每次突破的硬条件。 |
| 换手水平及异常程度 | 当日换手率、此前换手率分布、股本变动日期 | 高量是否只是大股本效应，或者来自流通盘变化？换手率也不是越高越好。 |
| 量价配合 | 放量倍数与突破幅度、收盘位置、上影线、实体方向一起看 | 区分放量站稳、放量滞涨、放量冲高回落。 |
| 放量持续性 | 已发生的连续放量日数、近 3／5 日量能变化 | 是否只有一次脉冲？当天不能预先认定明后天仍会放量。 |
| 放量时段 | 竞价、连续交易、临近收盘、盘后成交的金额与占比 | 放量是否主要来自某个特殊时段？需要分类数据或能准确对应时段的分钟数据。 |
| 突破阶段量能 | 固定突破时刻前后等长分钟窗口的成交量，并与历史同一时段比较 | 是突破发生时量能跟随，还是先出现大量成交后价格才勉强越线？ |

“RVOL_20 ≥ 1.5”或“≥ 2”可用作待检验的放量档位。绝对成交额下限、换手区间和分位阈值应按股票池及历史样本确定；不存在本文已经确认有效的统一数值。

### 2.4 盘中必须使用同时刻比较

```text
同时刻累计量倍数 = 今日开盘至 τ 的累计成交量
                   / 此前 N 个可比交易日开盘至同一 τ 的累计成交量均值

局部时段量倍数 = 今日某个已完成分钟区间的成交量
                 / 此前 N 个可比交易日同一区间成交量均值
```

两种比率回答不同问题：累计量反映截至当前的全天活跃程度；局部时段量反映突破附近是否突然活跃。均须固定分钟粒度、集合竞价与午休处理、盘后范围、有效样本数以及缺失状态。

例如：10:30 今日累计成交 600 万股，历史同一时刻平均为 300 万股，同时刻累计量倍数为 2。历史全天平均为 1,000 万股时，不能据 `600/1,000=0.6` 判断盘中缩量，也不能仅按已过交易分钟数线性外推全天量。

若输入来自 Tick，`volume/amount` 的当日累计值不能在每次推送时直接累加。差分恢复区间量还须处理跨交易日归零、重复／乱序推送、修订及断线缺口；基线不完整时区间量应标记未知。

**应保留的结果**：标准量与额、单位及原始证据引用、历史基准窗口与有效样本数、`RVOL_5/20`、成交额倍数、历史分位、缩量比、换手率及股本日期、量价关系、盘中累计／局部倍数和观察时刻。

### 2.5 容易误判的情况

- 基准窗口大量停牌或缺失，被填零后导致假放量；基准均值为零时输出无穷大。
- 用今日流通股本计算数年前换手，或者把总股本换手与流通股换手混在一起。
- 小成交额股票因此前更低量而出现高倍数，被误解为足够强的交易参与。
- 一字涨停时实际可成交数量受限；没有明显放量不能直接解释为没有需求，形态强也不代表可以按该价买到。
- 将除权、复牌或特殊交易时段导致的不可比量能，直接当作正常突破确认。
- 把供应商界面的“量比”与本文自定义的日成交量倍数混用；其分母和盘中时间归一化方法可能不同。

## 3. 同一板块多龙头股领涨

### 3.1 丰富后的含义

这一点同时包含四件事：股票属于同一明确板块；板块内有事先可以识别的领涨候选；多只候选在相近时间表现强势；其余成员也有一定跟随。

“龙头”需要区分身份。**产业龙头**来自主营业务、市场份额、行业地位等资料；**行情龙头候选**来自价格强度、成交活跃度与持续性。本文主要检测行情领涨，不能用成交额排名替代产业地位，也不能用事后涨幅最高的股票倒推它在此前已是龙头。

### 3.2 需要采集什么数据

| 数据 | 粒度／范围 | 用途 | 必要程度与注意点 |
| --- | --- | --- | --- |
| 板块 ID、名称、分类类型及来源 | 行业／概念维度 | 明确“同一板块”的含义 | 必需；行业层级与概念分类分别保留，不把不同供应商的同名板块自动合并。 |
| 板块成员名单及有效区间、当时可得时间 | 目标日及历史比较期间 | 确定排名、上涨比例、突破比例的股票集合 | 必需。今天的名单不能直接回填数年前。 |
| 全体成员的日线 `O/H/L/C/V/A` | 至少覆盖排名、平台、量能与均线所需窗口 | 候选排名、同步突破、成员跟随、整体表现 | 必需；只取几只知名股票无法计算板块广度。 |
| 成员上市退市、停复牌和数据完整性 | 与成员名单和行情对应 | 确定应统计对象、有效样本与覆盖率 | 必需；退出市场的历史成员也要保留。 |
| 板块指数日线及指数编制说明 | 目标日与相同历史窗口 | 观察板块趋势与相对大盘强弱 | 增强；没有该指数时可用明确命名的成员组合统计替代。 |
| 成员历史流通股本／市值、权重 | 对应有效日期 | 识别大市值中军、采用市值加权统计 | 只有使用相关定义时必需；当前权重不可直接回填历史。 |
| 事前龙头候选快照 | 至少保存名单生成时点、输入截止日、选取规则和排名 | 证明当天检测对象在观察前已确定 | 必需；这是派生结果快照，不是上游通用原始字段。 |
| 成员及板块／基准的分钟行情 | 同一个交易时刻和同一粒度 | 验证谁先突破、谁后跟随，量化同步时间差 | 判断盘中先后关系时必需。 |
| 主营业务、行业份额及资料发布日期 | 与判断日期对应 | 使用产业龙头或人工维护龙头名单 | 增强；人工名单也须有依据、生效日期和版本。 |

板块名单、行情和元数据必须同时具备“何时有效”与“何时可以知道”的证据。例如某概念归属在 t+2 日才公布，即使资料声称与 t 日事件相关，也不能用于 t 日的事前筛选。

### 3.3 先确定龙头候选，再判断当天是否领涨

可以从下列维度形成候选名单；所有用于事前排名的行情截至 `t-1`。

| 候选维度 | 所需数据与计算 | 作用与局限 |
| --- | --- | --- |
| 价格强度 | 近 20／60 日价格变化率在板块内的排名 | 找持续相对强势的成员；不能只看昨天涨幅。 |
| 相对板块强度 | 个股同周期表现减去板块表现 | 判断是否持续强于所属板块；这里的相对强弱不是 RSI 指标。 |
| 成交活跃度 | 近 20 日平均成交额及板块内排名 | 排除极低成交活跃度造成的偶然高涨幅。 |
| 持续性 | 最近若干日中保持强度前列的比例、持续强于板块的天数 | 区别一次脉冲和持续领涨，需要保存或重算历史排名。 |
| 结构强度 | 事前是否已接近平台上沿、是否站在中期均线上方 | 补充行情结构，不能用当天突破后的结果构造当天事前名单。 |
| 板块影响力 | 成交额占比；有历史股本与可比价格时可加流通市值占比 | 识别资金关注的中军或指数权重影响，不自动等同于涨幅领涨。 |

一种可验证的示例规则是：先以此前 20 日平均成交额筛掉明显不活跃成员，再按此前 20／60 日相对强度排序，选取前 3～5 只，保存截至前一日的名单。筛选门槛、多个排名如何组合以及并列处理必须预先固定；本文不预设已经验证有效的权重。成员不足时记录实际候选数量，不能补入板块外股票凑数。

若需要盘中更新候选，也可以生成新版本，但新版本仅能用于生成时刻之后的判断，不能替换当天开盘前的名单。

### 3.4 检测“多龙头同步”与“普通成员跟随”

“多龙头”至少需要 2 只不同证券满足所选强势条件；具体是否要求 2／3 只及候选通过比例应预先固定。只有 1 个有效突破事件时，时间差不能以零表示高度同步。候选行情缺失导致数量不确定时，应标记“无法判断”；已知候选不足 2 只则不能确认多龙头条件。

| 检测项 | 数据与计算 | 判断含义 |
| --- | --- | --- |
| 强势龙头数量／比例 | 事前候选中，当日上涨、表现强于板块且满足预定强势条件的数量／有效候选数量 | 检查是否有多只核心成员共同走强。强势条件与平台突破条件分别保存。 |
| 放量突破龙头数量 | 候选中同时满足第 1 点和第 2 点的数量 | 对“同板块多股同步放量突破”给出更严格证据，不要求每一种领涨都必然突破平台。 |
| 龙头表现领先程度 | 候选等权当日表现、普通成员当日表现、候选在板块涨幅分布中的位置 | 判断候选是否实际领涨，避免名单虽叫龙头但当天普遍落后。 |
| 龙头突破时间差 | 最早与最晚合格突破时刻之差；可比较预定如 30 分钟的窗口 | 检测盘中同步。日线只能证明同一天走强，不能证明谁先带动谁。 |
| 板块上涨比例 | 当日上涨成员数／有有效当日涨跌数据的合格成员数 | 判断上涨是否扩散。平盘保留在分母，停牌按预定资格规则处理。 |
| 板块突破比例 | 已确认平台突破的成员数／具备完整平台检测输入的合格成员数 | 判断是否出现结构性集体突破；同时输出检测覆盖率。 |
| 板块趋势广度 | 成员收盘高于自身 MA20／MA60 的数量与比例 | 区别全板块结构改善和仅当天反弹。 |
| 板块价格表现 | 板块指数变化率，或成员等权表现；同时看成员涨幅中位数 | 防止少数大权重拉高指数掩盖多数成员偏弱。 |
| 板块成交活跃度 | 固定可比成员集合的成交额合计及相对历史基准的倍数 | 检查板块交易参与是否同步增加，避免成员扩容造成假增长。 |
| 交易集中程度 | 事前龙头成交额之和／板块同一时段总成交额；再看非龙头上涨比例 | 区分只有核心股票活跃和交易活动扩散。集中度高本身不能单独判好坏。 |
| 极强／极弱成员分布 | 涨停、跌停成员数，及普通成员表现 | 补充板块分化程度；识别历史涨跌停需要对应日期的实际限价或已验证规则。 |

分母和覆盖率按每个指标分别确定：

```text
U = 当时已知且有效的板块成员，按预定规则排除未上市、已退市及当日认可停牌等不适用对象
D_m = U 中指标 m 所需数据完整的成员
指标覆盖率 = size(D_m) / size(U)
上涨比例 = D_涨跌 中上涨的成员数 / size(D_涨跌)
突破比例 = D_突破 中已确认突破的成员数 / size(D_突破)
```

真实零成交但仍正常交易的股票不能仅因成交为零就假定停牌。缺行情的成员不应被伪造为平盘，也不能不披露地从统计里消失。覆盖率不足、样本太小或分母为零时，保留可算预览值并把对应正式判断标为“无法判断”。覆盖率门槛是数据质量参数，应在使用前固定，不按涨跌结果调整。

若无板块指数，日级等权成员表现可定义为 `mean(R_i(1,t))`，标明“成员等权表现”。多日组合表现需逐日使用当时的成员和既定权重／调整规则，连乘 `1+日组合表现`；不能把不断变化成员名单的收盘价直接求平均。成员集合变化、缺数据或研究价格的复权口径限制都应披露，它不自动等同于供应商行业指数收益。

在小板块或单只股票影响很大时，额外计算剔除目标股、剔除事前龙头后的成员表现。否则目标股的大涨可能同时抬高板块指标，形成对自身的重复确认。

### 3.5 示例、结果和误判边界

例如：某板块当天有 40 只合格成员，行情完整。事前 5 只龙头候选中 3 只放量突破，板块共 28 只上涨、8 只突破，分别得到 70% 上涨比例和 20% 突破比例。若 5 只候选全部上涨，则非龙头上涨比例为 `23/35≈65.7%`，可单独观察跟随情况。实际强弱仍须与该板块历史常态、候选表现及市场环境比较。

**应保留的结果**：板块来源与成员版本、事前候选名单及依据、候选有效数、强势数、放量突破数、时间差、板块和非龙头上涨比例、突破比例、趋势广度、板块表现、成交额变化、集中度和每项覆盖率。

容易误判的情况包括：

- 用事后赢家定义此前龙头；用今天的热门概念归属解释过去的上涨。
- 仅两只大权重上涨就判断板块整体共振；忽略普通成员普遍下跌。
- 同一股票跨多个概念被重复计入“独立龙头数量”；每个板块内部按证券身份去重，跨板块汇总也要单独去重。
- 仅有日线却写成“龙头在 10:00 带动其他股票”；领先时间关系必须有分钟证据，且时间先后本身也不证明因果。
- 缺行情主要发生在弱势成员，导致可见样本的上涨比例偏高。
- 今日成员数量多于历史，直接用板块总成交额增长认定板块放量。

## 4. 中长期均线向上

### 4.1 丰富后的含义

均线向上描述的是过去一段时间价格均值正在抬高。需要分别判断：哪些周期向上、向上多少、持续多久，短中长期的相对排列如何，以及当前价格是否已远离均线。

本文以收盘价简单移动平均线 SMA 为基础，重点观察 MA20、MA60、MA120；MA20 用于较近趋势，MA60／MA120 用于更长背景。均线方向、均线多头排列和均线交叉是三个不同条件：长均线刚转向上时未必已经多头排列；多头排列也可能暂时仍在但所有均线已经向下。

### 4.2 需要采集什么数据

| 数据 | 粒度／范围 | 用途 | 必要程度与注意点 |
| --- | --- | --- | --- |
| 个股历史收盘价 | 日线，覆盖最长均线及其斜率观察窗口 | MA 值、方向、变化率、排列和交叉 | 必需。连续完整样本下，比较 MA120(t) 与 MA120(t-10) 至少需 130 个收盘样本。 |
| 对应日期、交易日历和停复牌状态 | 与全部收盘样本对应 | 确认窗口完整性与实际跨越时间 | 必需；认可空槽和未知缺口不能同等处理。 |
| 同系列复权快照、数据修订信息 | 覆盖均线及参考值 | 保证今天和此前均线可比较 | 必需。历史价格重算后须使用同版本的全部指标。 |
| 当前 `C`，增强可加 `H/L` | 目标日 | 股价处于哪些均线上方、是否回踩及收盘守住 | `C` 必需；日内触碰需 `H/L`，先后路径需分钟线。 |
| 足够的历史 `H/L/C` 或可信 ATR 状态 | 与偏离检测对应 | 波动调整后的价格偏离 | 使用 ATR 偏离时必需。 |
| 已完成周线，或可完整聚合的日线和周历 | 如观察 MA10／20／30 周线 | 日周多周期方向是否一致 | 增强；本周未结束的周线只能作为临时观察。 |

### 4.3 需要计算并检测什么

```text
MA_N(t) = mean(C(t-N+1), ..., C(t))
K 日均线相对变化 = MA_N(t) / MA_N(t-K) - 1
K 日平均相对变化 = [MA_N(t) / MA_N(t-K) - 1] / K
股价偏离率 = C(t) / MA_N(t) - 1
波动调整后的偏离 = [C(t) - MA_N(t)] / ATR(t-1)
```

第一行是 SMA 的基础计算，窗口包含当前 bar。[SMA 定义](https://www.tradingview.com/support/solutions/43000696841-simple-moving-average/) 其余是本检测需求定义的变化与偏离指标。“K 日平均相对变化”是简单归一化斜率，不是复合年化收益，也不是图表显示角度。

| 检测项 | 具体观察数据 | 判断目的 |
| --- | --- | --- |
| 每条均线的当前值 | MA20、MA60、MA120，必要时 MA30 | 保存趋势背景原值，不能只留下“向上”标签。 |
| 均线方向 | 分别比较 MA20(t) 与 MA20(t-5)、MA60(t) 与 MA60(t-5)、MA120(t) 与 MA120(t-10) | 区分短中期改善和中长期同步向上。窗口是示例，可配置。 |
| 向上幅度 | 上述相对变化率、每日归一化斜率 | 区分明显上行和接近零的走平；跨价格不同股票不能只比较元／日。 |
| 上行持续性 | 最近 5／10 次日终观测中，均线相邻值上升的比例与最长连续次数 | 排除单日跳涨使均线暂时抬头。遇空槽或缺口需按规则中断或标记。 |
| 方向加速／减速 | 当前 K 日变化与此前相同长度窗口的变化 | 观察上行是否增强、放缓或接近转平；不单独作为必需买入条件。 |
| 均线排列 | MA20、MA60、MA120 两两差值及是否满足 `MA20 > MA60 > MA120` | 检测结构排列，与方向条件分开输出。 |
| 股价位置 | `C` 与每条 MA 的差值、偏离率 | 看价格是否站在趋势支撑参考之上，以及离均线有多远。 |
| 均线间距 | 如 `(MA20-MA60)/MA60`、`(MA60-MA120)/MA120` | 区别均线粘合、开始扩散和扩散过大。 |
| 交叉事件及距今天数 | 短长均线差值此前最后一个非零方向为负，当前转正的确认事件及时间 | 相等区间保留此前方向；“正、零、正”不算金叉。方向未知时先建立状态。记录结构变化发生多久，不要求交叉恰好与突破同日。 |
| 趋势背景的事前稳定性 | 同时保存 t-1 与 t 的均线方向、排列 | 区分此前已向上和仅今天大涨后才转向上。 |
| 日周一致性 | 日线均线方向与已完成周线均线方向 | 作为更长趋势的补充。5 根交易日日线不是任何时点都等于一根日历周线。 |

在无空槽且采用固定 N 样本的 SMA 时，`MA_N(t)-MA_N(t-1)=[C(t)-C(t-N)]/N`。因此均线单日抬头也可能只是较低旧价格移出窗口；它本身不能证明有新增资金持续推动。

### 4.4 示例、结果与不同趋势阶段

例如：今日 MA60=10.20，5 个交易日前为 10.00，则五日相对变化为 2%，简单平均相对变化约 0.4%／日；今日 MA120=9.70，10 个交易日前为 9.72，则其十日相对变化约 -0.21%。这个组合说明中期均线在升、长期均线仍略降，不能写成“中长期均线全部向上”。

若今日收盘 12.00、MA60 为 10.00，偏离率是 20%。即使方向和排列均满足，也应把距离单独展示；是否偏离过大需要结合个股波动常态，而不能只据 20% 一刀切。

**应保留的结果**：各周期均线值、对比日期及参考值、相对变化、上行持续比例、均线排列、价格偏离、均线间距、最近交叉时间、t-1／t 状态变化以及周线完成状态。

这一条件还决定信号偏向哪类行情：

- **底部反转初期**：MA20 可能先转向上，MA60／MA120 仍走平或向下。可记录为中长期条件尚未满足，而不是遗漏或假定已满足。
- **已有上升趋势中的整理后突破**：MA60／MA120 已向上，更符合用户提出的完整中长期趋势背景。
- **趋势后段继续创新高**：多条均线仍向上，但价格偏离较大、上行速度可能减弱。仅凭排列不能把它当成刚启动。

### 4.5 容易误判的情况

- 按图上的“45 度角”判断趋势；角度会随横纵轴缩放改变，应检测数值斜率。
- 把 MA20 上行写成中长期均线全部向上，或把 `C>MA60` 写成 MA60 本身向上。
- 只比较前后两个点，没有检查中间是否持续向上；或者用单日跳涨证明长期趋势改变。
- 历史样本不足时缩短 MA120 的窗口，仍沿用 MA120 名称。
- 跨未知缺口继续计算，或用当前复权均线与此前保留的旧快照均线比较方向。
- 用尚未完成的日／周均线给出最终信号，之后回落却没有撤销临时结论。

## 5. 与大盘同频共振

### 5.1 丰富后的含义

“同频”至少有两个维度：使用相同的观测周期，以及处于相近的上涨阶段。“共振”则需要同时看到个股、板块和市场环境的支持，而不能仅凭大盘当日收红。

这一点要回答：所选基准是否有向上的趋势；市场中是否有足够多股票共同走强；交易活跃度是否支持；目标板块和个股是否跟随或领先。高相关并不等于向上共振，因为一起下跌同样可能高度相关。

### 5.2 先固定“大盘”代表什么

- 为股票池事前登记一个主要基准，如选定的宽基指数；如确有风格差异，可另加一个事先登记的风格参考指数。
- 基准选择依据是股票池覆盖与风格匹配，不能每天从多个指数中选择涨得最好的一个作为“共振大盘”。
- 指数代表一个组合的走势；市场广度代表指定市场内股票的普遍表现。二者分别计算，并写清市场是否包含沪、深、北市场以及 ST、新股等资格规则。
- 个股日线突破应优先与板块、大盘同日和相同 5／20 日窗口比较；盘中观察统一到同一已完成分钟槽，避免拿个股最新价与大盘几分钟前的价格比较。

### 5.3 需要采集什么数据

| 数据 | 粒度／范围 | 用途 | 必要程度与注意点 |
| --- | --- | --- | --- |
| 主要基准指数 `O/H/L/C`、时间及完成状态 | 当日及覆盖趋势、相对表现的历史区间 | 指数上涨、均线方向、突破／回撤 | 必需。价格指数与全收益指数不得不加说明混用。 |
| 已登记风格指数行情 | 与主要基准同步 | 识别大盘整体与目标股票风格之间的差异 | 增强；单独解释，不能事后替换主要基准。 |
| 市场证券名单及历史资格状态 | 对应每个观察日 | 确定市场广度的统计对象 | 使用市场广度时必需；名单应可追溯。 |
| 市场股票行情 `C`、有效日涨跌基准、历史收盘价、`A` | 日线；盘中则增加相应快照／分钟 | 上涨比例、涨幅中位数、站上均线比例、成交额 | 必需。指数一根 K 线不能替代全部股票的广度数据。 |
| 成员停复牌、上市退市及数据完整性 | 与名单和行情对应 | 广度分母、可比较样本及覆盖率 | 必需，规则与第 3 点相同原则。 |
| 指数自身成交量／额或明确范围的市场成交额 | 与价格同一时段 | 观察市场活跃度是否增加 | 使用量能共振时必需；先核实指数成交字段覆盖范围，不能默认代表全市场。 |
| 目标个股和板块行情／组合表现 | 与基准相同日期和观察窗口 | 个股—板块—市场相对强弱 | 必需，与第 1～3 点共用。 |
| 市场股票历史涨跌停价格／状态 | 对应日期 | 涨跌停数量、极端分化 | 增强；不能统一以涨跌幅 10% 推定所有股票的涨跌停状态。 |
| 个股、板块、基准及所需市场成员的分钟行情 | 同粒度、同一截止时刻 | 盘中同向率、强弱比较、量能与突破时间差 | 盘中共振所需。仅订阅候选股不足以得到盘中全市场广度。 |

市场日涨跌应使用已明确的“当日相对上一交易日”基准；若采用同一研究序列的相邻交易日变化，应标明该定义。不能直接复用可能回退为上一分钟收盘价的 Tooltip“昨收”字段来统计全市场当日涨跌。

### 5.4 需要计算并检测什么

| 检测层次 | 数据／指标 | 要判断的问题 |
| --- | --- | --- |
| 大盘当前方向 | 基准当日、5 日、20 日价格变化率 | 今天上涨是否只是此前下跌中的单日反弹？ |
| 大盘趋势背景 | 基准收盘相对 MA20／MA60 的位置，均线斜率 | 大盘自身是否处于上行、走平或下行背景？ |
| 大盘结构位置 | 与其前期平台、高点及近期低点的距离，若使用突破则沿用第 1 点的事前识别 | 是刚走出整理、接近压力，还是仍在较深回撤中？ |
| 市场涨跌广度 | 上涨／下跌／平盘数量、上涨比例、股票涨幅中位数 | 指数上涨是否得到多数股票支持？ |
| 市场趋势广度 | 站上 MA20／MA60 的成员比例及其近 5 日变化 | 是短暂普涨，还是更多股票的结构正在改善？ |
| 市场成交活跃度 | 同一可比股票集合的成交额合计，相对此前 20 日均值的倍数 | 大盘或市场上涨是否伴随更多交易参与？ |
| 极端分化程度 | 涨停／跌停数量、上涨与下跌成交额分布 | 市场是否存在一边拉指数、一边大量股票走弱的分化？ |
| 板块相对市场强度 | 同周期板块表现减基准表现 | 板块是否得到市场支持，并且表现更强？ |
| 个股相对板块强度 | 同周期个股表现减板块表现 | 个股是否在所选板块中处于领先状态？ |
| 三者方向一致性 | 同一窗口的个股、板块、基准表现是否同时为正；趋势方向是否一致 | 区别共同走强与弱市中的个股逆势上涨。 |
| 同步发生程度 | 最近若干日同时上涨的比例；盘中则计算同一时间槽的方向与时间差 | 检查“一起走强”是否持续，而不是偶然同一日收红。 |
| 相关性，增强 | 对齐后的个股／板块／基准日收益序列的相关系数 | 描述联动程度，不能代替方向、趋势、相对强弱及广度。样本不足或方差为零时不可计算。 |

核心比较可写为：

```text
R_个股(k,t) = C_个股(t) / C_个股(t-k) - 1
RS_个股对板块(k,t) = R_个股(k,t) - R_板块(k,t)
RS_板块对大盘(k,t) = R_板块(k,t) - R_大盘(k,t)
市场上涨比例 = 合格且数据完整的上涨股票数 / 合格且日涨跌数据完整的股票数
市场 MA20 广度 = 收盘高于 MA20 的合格股票数 / MA20 及收盘输入完整的合格股票数
市场成交额倍数 = A_市场(t) / mean(A_市场(t-20), ..., A_市场(t-1))
```

`R_板块` 若来自官方指数，按该指数的可比序列计算；若来自成员组合，沿用第 3.4 节的逐日组合定义。`RS` 为变化率之差，展示时用百分点，不能与百分比倍数混淆。上述相对强弱是描述性指标，不是已经剔除风险、行业或风格影响的超额收益模型。

市场成交额合计按证券身份去重，仅包含约定股票集合，不把股票、ETF、指数和重叠概念板块金额重复相加。比较历史时固定当时已知的可比集合，披露剔除对象和覆盖率；逐日市场原始总额可以另存，但成分变化明显时不能直接将其增长归因为放量。市场广度使用第 3.4 节的逐指标资格、分母和覆盖率规则。

### 5.5 日线、盘中与情景判断

日线至少同时看三个时间尺度：当日方向用于观察突破当天环境；最近 5 日用于观察近期持续性；最近 20 日及均线用于观察趋势背景。它们可以不同向，应保留分歧，而不是择一报喜。

盘中则需要共同截止时刻，检查三者相对当日开盘或同口径前收的表现、最近固定分钟窗口的表现，以及相对历史同时刻的成交活跃度。相对开盘、相对前收、相对上一分钟是不同指标，应分别命名。若基准行情陈旧或某一层数据未完成，该时刻的同步判断为“无法判断”。

| 观察到的情况 | 可以得出的描述 | 不能直接得出的结论 |
| --- | --- | --- |
| 个股突破，板块多成员强势，大盘趋势向上且广度改善 | 三个层面存在共同走强的证据 | 趋势一定会延续或这次突破一定成功。 |
| 个股突破、板块偏弱，大盘普涨 | 更接近个股独立强势或普涨中的个股突破 | 已满足同板块多龙头条件。 |
| 个股和板块强，大盘持续下跌 | 板块／个股逆势强势 | 已满足向上的大盘共振。 |
| 指数上涨，但大多数股票下跌、涨幅中位数为负 | 指数与广度分化 | 全市场共同走强。 |
| 大盘单日反弹，MA60 仍下降，个股突破 | 短线方向同向、较长趋势尚未同向 | 已满足所有时间尺度的趋势共振。 |

例如，同一 5 日窗口内，个股研究价格变化 +8%、板块可比表现 +5%、大盘基准 +2%，则相对强弱分别为 +3 和 +3 个百分点；如果大盘为 -2%，个股和板块即使仍很强，也应描述为逆势强势。具体数值仅演示逻辑。

**应保留的结果**：主要／辅助基准身份、比较周期与截止时刻、三者表现、两个相对强弱、指数均线状态、市场上涨比例及中位数、趋势广度、成交额倍数、极端分化数据、同步情况及每项覆盖率。

### 5.6 容易误判的情况

- 用个股日线、板块周线和大盘某一分钟上涨拼成“同频”。
- 大盘高相关但实际共同下跌；个股强于下跌大盘但自身也下跌，仍被写成向上共振。
- 用涨得最好的指数替换预先选定基准，或者把指数上涨当作多数股票上涨。
- 汇总多个重叠行业／概念的成交额，重复计算市场活跃程度。
- 在盘中用全天历史成交额作为直接分母，或用不同时间戳的行情比较相对强弱。
- 对历史广度使用当前仍存续的股票池，遗漏历史退市及退出成分，产生样本偏差。

## 6. 可交易性检查

### 6.1 判断目的与适用阶段

可交易性回答的是：对于指定证券、账户、买卖方向、数量、订单类型、价格约束和执行时段，当前是否具备可接受的报单及成交条件。它依赖具体交易计划；同一只股票、同一时刻，小额买入和大额买入的结果可能不同，买入和卖出的结果也可能不同。

| 阶段 | 可以检查什么 | 结论边界 |
| --- | --- | --- |
| 日线流动性初筛 | 日均成交量／额、交易活跃程度、历史零成交／停牌情况、已知证券资格 | 只能形成候选资格或流动性参考，不能确认次日的盘口、账户状态或成交价格。 |
| 指定计划的交易前检查 | 当前证券及账户状态、有效盘口、允许价格和数量、资金／可卖数量、成本与规模 | 必需输入齐全时，判断该计划在检查时刻是否满足预设执行条件；结果应带有效期。 |
| 已有委托的状态复核 | 剩余委托、冻结、成交／撤单状态及更新后的行情 | 若后续接入交易环节，用于避免重复占用和依据旧状态继续判断；本文不实现报单或撤单。 |

没有账户或交易计划时，仍可输出市场侧的数据和初筛结果，但“该账户的该笔计划是否可执行”应为“无法判断”。没有完整历史盘口、账户或规则版本时，也不能仅靠日 K 线重建当时的完整可交易性。

### 6.2 需要采集什么数据

| 数据 | 需要的字段／含义 | 用途及必要程度 |
| --- | --- | --- |
| 交易计划 | 证券与账户标识、买／卖方向、数量或金额、订单类型、限价或保护价格、计划执行起止时间、是否接受部分成交、计划版本 | 交易前判断必需。这是策略／用户给定输入，不是行情字段；仅给金额时应按价格与数量规则形成明确数量后再检查。 |
| 证券与时段状态 | 当前停复牌／临时停牌状态、所在交易阶段、允许申报的品种和订单类型、状态时间 | 判断是否允许该类委托。集合竞价、连续交易和盘后阶段分别处理，不能共用连续竞价的盘口假设。 |
| 当日价格与数量约束 | 当日实际涨跌停价或明确无涨跌幅限制的状态、适用申报价格范围、最小价格变动单位、申报数量上下限及递增单位、规则版本 | 判断价格、数量是否合法。没有涨跌幅限制不代表完全没有申报价格约束；不在本文硬编码统一的涨跌幅或数量规则。 |
| 实时可见盘口 | 买卖各档价格和数量、实际可见档数、证券身份、行情时间、接收时间、来源、数量单位、缺档状态 | 价差、对手盘深度和静态成交价格估算必需。买入检查卖盘，卖出检查买盘；不能假设固定五档或把未提供的档位当作零。 |
| 最近成交与短时量能 | 最新成交价及其时间、此前已完成 1／5／15 分钟成交量和成交额，必要时逐笔成交与交易时段 | 观察当前活跃度和计划规模。最新成交价不等同于当前可以买到／卖出的价格。 |
| 历史流动性 | 此前 20 日等已登记窗口的成交量／额、有效交易天数、停牌／异常事件、必要时历史同一时段量能 | 日线初筛、规模比率及当前流动性是否异常。数量和金额口径必须一致。 |
| 账户资格与连接状态 | 账户可用状态、目标市场／品种／方向权限、限制信息、交易连接状态及检查时间 | 账户侧报单条件必需。能获取行情不代表拥有交易权限；未知权限不能按已开通处理。 |
| 可用资金与可卖数量 | 买入侧可用资金及冻结依据；卖出侧目标证券可用数量及冻结／在途状态；快照时间 | 根据方向检查。持仓总量不等于可卖数量，总资产不等于可用资金；不以研究价格估值替代账户实际余额。 |
| 未完成委托及本地预占 | 同证券／账户已有委托、方向、价格、数量、已成交与剩余数量、撤单确认状态；尚未反映到账户快照的预占 | 避免重复报单或重复使用资金／股份。与账户冻结口径对账，不能把已扣减的冻结再扣一次。 |
| 费用与执行容忍度 | 适用账户和交易方向的佣金、最低收费、税费等规则及日期；允许价差、估算成本、规模比率和行情最大陈旧时间 | 计算成本及判断是否可接受。阈值来自明确配置和后续验证，本文不提供统一适用费率或阈值。 |

盘口、申报价格、涨跌停价和账户资金计算使用真实交易价格与已核实的实际数量单位。趋势图的前复权平台可以作为信号依据，但用于报单价格约束前应有明确、可验证的价格基准对应关系，不能直接把历史前复权价当作当前可申报价。

### 6.3 需要计算并检测什么

以下盘口公式用于已确认适用的连续竞价阶段。其他交易阶段需有独立判断规则，规则不明时保留未知状态。

| 检测项 | 数据与判断方法 | 需要区分的结果 |
| --- | --- | --- |
| 证券与账户是否允许该委托 | 交易阶段、证券状态、订单类型、账户权限及交易连接状态 | 已知不允许为“不满足”；状态未知为“无法判断”。交易连接正常本身不证明权限齐全。 |
| 委托参数是否合法 | 检查方向、价格、价格步长、申报范围、数量及递增单位 | 参数不满足时报告具体原因；改变数量、价格或订单类型后，应生成新计划再检查。 |
| 对手盘是否存在 | 买入观察卖盘，卖出观察买盘，并限制在计划允许的价格范围内 | 明确无合格对手盘、未提供盘口和行情陈旧是不同原因。最新价触及涨跌停不能单独证明某个方向可成交。 |
| 买卖价差 | 有效买一、卖一的差额及相对中间价的基点值 | 评价即刻交易的报价摩擦。正常连续竞价下双边报价不完整、数量无效或出现无法解释的倒挂，不能硬算普通价差。 |
| 限定价格内可见深度 | 按计划方向，累计价格满足约束的对手盘数量，与计划数量比较 | 输出覆盖比例和缺口。可见深度足够只支持静态估算，不保证订单到达时仍存在。 |
| 静态盘口均价 | 在不超过价格约束的可见档位上，按价格优先模拟取量 | 只能估算当前快照下的结果；深度不足时不能为剩余数量虚构价格或计算完整成交均价。 |
| 相对流动性的规模 | 计划数量／此前固定窗口成交量、计划金额／此前日均成交额，必要时与历史同时段量能比较 | 标注每个分母覆盖的窗口。小额日均占比不一定意味着当前几分钟也有足够流动性。 |
| 价格成本与费用 | 静态盘口均价相对固定交易参考价的成本，加适用费用；若有验证过的模型，再单列延迟／冲击估计 | 区分价差、静态跨档成本、费用和额外模型假设；避免重复计入同一成本。 |
| 资金／可卖数量是否足够 | 买入以适用报单预占规则计算所需资金和费用；卖出比较计划数量与实际可卖数量 | 可用资金或可卖数量不足为“不满足”。仅有总资产／总持仓时无法完成此项。 |
| 行情与账户状态是否新鲜 | 检查行情年龄、接收延迟、账户快照年龄、连接状态和各输入时点差 | 必需状态过期、未知或跨时点不一致时，当前执行判断为“无法判断”，不得沿用旧通过结果。 |

为便于核查，核心指标定义如下：

```text
中间价 M = (有效卖一价 + 有效买一价) / 2
价差基点 = (有效卖一价 - 有效买一价) / M × 10,000

Q = 计划交易数量，统一为实际股数
买入限价内可见量 = sum(卖价 <= 买入限价的有效卖档数量)
卖出限价内可见量 = sum(买价 >= 卖出限价的有效买档数量)
可见深度覆盖倍数 = 适用对手盘的限价内可见量 / Q

静态盘口均价 P_book = sum(档位价格 × 模拟取用股数) / Q
                      仅在全部 Q 均有可见合格档位覆盖时计算

买入价格成本基点 = (P_book - P_ref) / P_ref × 10,000
卖出价格成本基点 = (P_ref - P_book) / P_ref × 10,000
费用基点 = 本笔适用费用金额 / (Q × P_ref) × 10,000

近 5 分钟量能规模比 = Q / 此前已完成 5 分钟区间成交股数
日均量规模比 = Q / 此前 N 个有效可比交易日的平均成交股数
行情年龄 = 检查时间 - 行情源时间
```

`P_ref` 必须预先固定为同一时刻、同一实际价格基准的参考，例如检查时中间价；不能在成交后挑选有利参考。`Q` 和各分母必须为正。单边无报价时中间价不可算，不能将空价补零后继续计算；时钟明显错位导致负行情年龄时应先核实时间，不能把它当作特别新鲜的行情。

`P_book` 对中间价的价格成本通常已经包含跨过买卖价差及可见档位造成的价格差，不能再机械加上完整价差。延迟、撤单、队列和市场冲击若无可信模型，应明确无法估计，不能以静态价格成本冒充完整预期执行成本。

上面的 5 分钟规模比是已完成历史区间的参考比率，不是未来 5 分钟的真实参与率。若计划分段执行，应按计划区间另行估计未来成交量并保留误差；不能用尚未发生的实际成交量提前证明计划可执行。

可用资金／数量以账户返回语义为准。若其已扣除既有委托冻结，不能再次扣除；只对尚未被快照反映且有明确依据的本地预占另行处理。撤单请求发出不代表委托已撤销，只有相应确认和状态更新后才能认定资源释放。

### 6.4 按方向解释涨跌停、限价与排队

- 买入在限价范围内需要卖方数量；卖出需要买方数量。同一个涨停状态对两个方向的成交条件不同，应分别看当时对应的盘口与允许申报规则。
- 如果真实、有效盘口显示限价内没有对手方数量，就不能通过“立即成交”的检查；如果盘口缺失，则是无法判断是否存在对手方数量。
- 允许挂限价单排队，是另一种执行计划。盘口量无法单独确定自己的队列位置、前方委托撤单和未来流入订单，不能据此承诺成交概率或等待时间。
- 深度不足时可以描述“当前可见价格范围只能覆盖部分数量”。是否接受部分成交、降低数量或改变价格约束取决于原计划；不能在检测中静默修改计划使其通过。
- 本节只检查观察时刻和指定执行区间的条件，不推导未来退出一定顺畅。若计划对退出流动性也有要求，应另行保存该要求及其估计依据。

### 6.5 数值示例

假设处于已确认适用的连续竞价阶段，全部数量已核实为股；有效盘口为买一 10.00 元，卖一 10.02 元、3,000 股，卖二 10.03 元、4,000 股。计划买入 6,000 股，限价 10.03 元。

- 中间价为 10.01 元，价差约为 19.98 个基点。
- 限价内可见卖量为 7,000 股，覆盖倍数约 1.17。
- 静态取量为 10.02 元买 3,000 股、10.03 元买 3,000 股，估算均价为 10.025 元；相对检查时中间价的买入价格成本约为 14.99 个基点，尚未计费及动态变化。
- 若此前已完成 5 分钟成交 100,000 股，计划相对该区间的规模比为 6%；若此前日均成交 2,000,000 股，日均量规模比为 0.3%。两个比例都不能保证立即成交。
- 若该账户的限价买单按限价全额预占，本金需求为 `6,000×10.03=60,180` 元，并须另外计入适用费用；不能以静态均价对应的 60,150 元代替报单所需资金。
- 同一盘口下，如果计划改为限价 10.02 元，当前可见合格数量仅 3,000 股，覆盖 50%。这支持“有部分可见深度”的描述，不能视为原定 6,000 股立即完整成交条件满足。

示例只核算报价与数量关系。账户权限、资金、委托规则、行情新鲜度等仍须分别检查；盘口可能在订单到达前被撤销或被其他订单消耗。

### 6.6 结果状态、复核时点与应保留信息

可交易性与五项形态条件分别输出“满足／不满足／无法判断”，并增加检查阶段、计划版本及观察时间：

| 结果 | 适用解释 | 示例 |
| --- | --- | --- |
| 满足 | 当前所选执行规则的必需输入齐全，全部必需检查通过 | 指定限价和数量合规，资源足够，所需市场与账户状态有效，并符合登记的流动性和成本条件。只表示检查通过。 |
| 不满足 | 至少一项有充分数据证明未达到要求 | 可卖数量不足、证券暂停该类交易，或要求立即完整成交而限价内可见深度不足。 |
| 无法判断 | 没有已证实的不满足项，但仍有必需信息缺失、过期或无法核实 | 没有账户权限依据、必要盘口缺档、行情断线，或尚未给出计划数量。 |

每个子项独立保存结果。若已有明确不满足项且同时有未知项，总结果可为“不满足”，但未知项与原因仍须保留，不能据此声称所有检查都已完成。只有所有必需项通过才能输出“满足”；增强分析缺失不扩大为无关必需项失败。

**应保留的结果**：原始形态信号引用、交易计划及版本、买卖方向、证券和账户状态依据、行情／账户／规则版本与时间、价差、限价内对手量、覆盖比例、完整／部分静态估算、参考价格及成本、量能规模比、资金／可卖数量核对、全部未通过或未知原因、检查有效期。

日终信号到下一交易时段、计划价格或数量改变、行情过期、交易阶段切换、账户委托／资金／持仓变化时，都需要重新检查相应执行条件。日终流动性初筛通过不能自动延长为下一交易日的执行通过；复核结果也不能改写原先的五项形态事实。

### 6.7 数据来源与常见误判

可交易性读取独立的标准实时盘口：实际各档价量、数量单位、行情/接收时间及可用档数。各来源在实时契约下分别验收；QMT 原字段只是其中一种映射，详见接入规范，不限定所有来源使用同名字段。

账户、资产、持仓与委托属于独立交易侧契约。供数来源可替换不代表账户、下单、资金和权限可以随之替换；账户市场权限、费用及资源冻结不能仅由行情推导。

常见误判包括：

- 将最新成交价或前复权研究价当作当前实际可成交报价。
- 不区分买卖方向，看到封板就统一标记为“可交易”或“不可交易”。
- 可见盘口量足够便认定保证成交；深度不足便以最后一档价格虚构剩余成交。
- 将日均成交活跃当作当前有流动性，或把过去 5 分钟规模比写成未来真实参与率。
- 未检查具体数量、账户可用资源与已有委托，只按证券本身给出可交易标签。
- 重复扣减已被冻结的资金／股份，或在撤单尚未确认时提前认为资源已释放。
- 将静态盘口成本、价差、费用和冲击重复相加，或者没有模型却输出精确成交概率。
- 使用不同时刻的盘口、持仓和资金，或以过期快照继续保留执行通过结果。

## 7. 五项条件与可交易性的合并数据清单

本节用于核对五项形态条件与独立可交易性检查的采集范围。同一份个股日线可以服务多项检测，板块和市场层面的指标需要扩大覆盖对象；账户、交易计划及实时盘口则服务具体执行检查。

### 7.1 需要保留的原始及基础数据

| 数据集合 | 最少需要的字段／含义 | 覆盖对象和时间 | 支持条件 |
| --- | --- | --- | --- |
| 证券身份与历史资格 | 证券代码、市场、证券类型、上市退市日期、交易状态及有效时间 | 目标市场的当前及历史相关股票 | 全部，尤其板块／市场统计分母。 |
| 个股日线 | 时间、`open/high/low/close/volume/amount`、完成状态；日涨跌计算另需已核实的前收基准 | 目标股、板块全部成员、市场广度所需股票 | 1～5。 |
| 研究价格与数量口径 | 来源、复权方式及系列快照、数量和金额单位、交易时段范围 | 全部输入区间 | 防止假突破、假放量、假斜率。 |
| 板块关系 | 板块 ID、分类来源／类型／层级、成员身份、生效失效时间、可得时间 | 行业、概念及当时成员 | 3、5。 |
| 指数行情与定义 | 指数身份、价格／收益口径、日期、OHLC；有用时加量额及其范围 | 主要基准、预先指定的辅助基准、可得板块指数 | 3、5。 |
| 历史股本 | 流通股本及单位、有效日期、发布／可得日期 | 使用换手率或市值权重的股票及历史区间 | 2、3 的相应增强判断。 |
| 历史交易状态与限价 | 停复牌、上市阶段、ST 等资格信息、当日涨跌停价格／已验证计算依据 | 对应每个观察日 | 量能解释、候选资格、极端分化判断。 |
| 日历及覆盖证据 | 交易日、时段、认可空槽、未知缺口、行情时间、接收时间与完成依据 | 与全部输入一致 | 全部；缺数据与不满足条件分开。 |
| 分钟行情，按需 | 时间与实际覆盖区间、OHLC、每 bar 量额、完成／缺失状态 | 候选股、所需板块成员、指数；若算市场盘中广度则覆盖所需市场 | 盘中突破、同时刻放量、领先顺序及共振。 |
| 产业地位／事件材料，按需 | 资料来源、业务／行业事实、发布时间、生效区间、人工归类依据 | 使用产业龙头或需要解释特殊事件的对象 | 增强解释，不由 K 线替代。 |
| 实时实际价格与盘口 | 买卖各档价量、实际可见档数、数量单位、行情与接收时间、当前交易阶段及完整性 | 准备执行的证券及检查时刻 | 第 6 节对手盘、价差、深度及静态价格成本。 |
| 明确交易计划 | 证券、账户、买卖方向、数量、订单类型、价格约束、执行区间、部分成交约定及版本 | 每个待检查计划 | 第 6 节规模、参数合法性与计划对应的执行判断。 |
| 账户与委托状态 | 账户资格／连接、可用资金、可卖数量、既有委托、冻结依据、未反映的本地预占及各自时间 | 仅具体账户执行检查所需 | 第 6 节资源与权限核对，不属于全市场 K 线采集。 |
| 交易规则与成本配置 | 对应日期和品种的价格／数量／订单类型约束、账户费用、成本和流动性容忍度、新鲜度要求 | 对应账户、证券、方向及观察日期 | 第 6 节执行条件；与行情字段分开管理。 |

建议准备 2～3 年日线作为近期形态研究起点，并按最长指标及预热要求核对每只股票的实际覆盖；这不是充分验证策略的固定历史长度。研究不同市场阶段或评估长期效果时，需要更长、具备当时成员和元数据的历史样本。

分钟历史长度由所用比较基准决定：例如同时刻量能基准为此前 20 个可比交易日，就必须覆盖这些日子的完整同一时段；不能只保存今天分钟线却声称拥有历史同时刻量比。首次突破先后只看 5 分钟即可满足的需求，可采用 5 分钟基础；需要精确到 1 分钟时再使用 1 分钟数据，遵循既有数据策略。

### 7.2 哪些是后续计算结果，而不是上游直接字段

| 条件 | 至少需要保留的派生结果 |
| --- | --- |
| 1. 平台突破 | 平台窗口／上下沿／宽度／漂移／测试次数、突破幅度、收盘位置、上影比例、首次越过和确认时间、后续站稳状态。 |
| 2. 明显放量 | 历史均量／均额、量额倍数、分位、缩量比、换手率及分母依据、同时刻量比、量价关系。 |
| 3. 多龙头领涨 | 事前名单与排名依据、强势／突破候选数量、同步时间差、板块与非龙头广度、集中度、成员覆盖率。 |
| 4. 均线向上 | MA 值、相对变化与参考日期、持续性、排列、间距、股价偏离、交叉事件、日周状态。 |
| 5. 大盘共振 | 三层同周期表现、相对强弱、指数趋势、市场广度、中位数、成交额变化、同步指标及覆盖率。 |
| 独立可交易性检查 | 检查阶段与计划版本、价差、限价内深度及覆盖倍数、静态盘口估算与成本、规模比率、资金／可卖数量核对、各子项状态、有效期及未通过／未知原因。 |

每项结果还应能说明：对应哪个标的／板块／基准、观察时间、输入截止时间、参数、输入版本、数据是否完整，以及“满足／不满足／无法判断”。这是结果应有的信息，不规定数据库表、接口或计算服务的实现形式。

### 7.3 数据集合与来源能力对应关系

数据集合分别选择具备相应能力的来源，不要求一家供应商同时满足全部需求。来源 API 与字段名放在各来源接入规范中；业务需求读取统一字段和含义。

| 需要的数据 | 系统契约输入 | 来源必须验证的能力 |
| --- | --- | --- |
| 个股/指数日线与分钟线 | 标准时间/区间、OHLCVA、品类/时段、复权及完成状态 | 原生或可派生周期、历史覆盖、退市数据、量额单位、完成和历史修订；股票量为手、额为元，指数量额另验范围。 |
| 行业/概念成员 | 标准证券 ID、分类来源/体系/层级、成员有效期和可得时间 | 历史名单及 PIT 证据；同名不同分类不可直接合并。 |
| 历史股本、证券资格与限价 | 流通股本为股，证券身份/资格和日期有效限价 | 字段别名、单位、有效日期、发布/可得时间；当前资料不证明历史完整。 |
| 日历与复权依据 | 交易日历/时段契约、价格方法及快照 | 适用市场范围、事件、锚点、盘后与修订证据。 |
| 实时盘口 | 实际未复权报价、档位股数/品类单位、行情时间和状态 | 可见深度、实时延迟、权限、区间一致性；不能推导保证成交。 |
| 账户与委托 | 独立交易契约的资产、可卖数量、冻结和委托状态 | 账户归属、更新时点、本地预占与权限；不能由行情渠道代替。 |

QMT 是候选之一，其字段与官方资料集中在 [QMT 接入规范](2026-09-12-qmt-source-adapter-spec.md)。其他渠道须提供相同业务能力的验证证据，本稿不声称已找到或实测完整替代源。

行情 A、股本 B、板块 C 可以通过统一证券身份与有效/可得时间关联；每次检测固定全部来源、数据契约、系列及元数据快照。不能把来源 A 的部分日期和 B 的其余日期自动接成一条 K 线，也不能按另一家成员名单缩小未知覆盖的分母。

[Tooltip 文档](kline-tooltip.md)的现行业务输入同样遵守统一契约。早期昨收回退、总股本回退和缺失补零已归档为历史记录，不是检测输入规则。检测读取标准精度字段，结果与图表可共享来源和快照，但不能以 UI 格式化值替代计算输入。

## 8. 联合解释与判断时点

五项应先独立说明证据，再组合描述。一种结果可以是：“平台突破已确认、放量已确认、多龙头仅 1 只成立、中长期均线向上、大盘方向同向但广度偏弱。”这比只输出一个“趋势启动”标签更容易核查。

可交易性在此基础上单独说明，例如：“形态五项满足；计划限价内可见深度不足，当前执行条件不满足。”没有指定账户与交易计划时，仅保留市场侧初筛；不能把它升级为账户侧完整执行确认。

### 8.1 状态不能混用

| 状态 | 含义 | 示例 |
| --- | --- | --- |
| 满足 | 所需数据完整，达到预先登记的判断条件 | 完整日线收盘超过此前确定的平台与容差。 |
| 不满足 | 数据完整，但条件未达到 | MA120 的指定窗口斜率仍为负。 |
| 无法判断 | 必需数据缺失、不可比、过期或样本不足 | 板块历史成员未知、同时刻分钟基准缺失。 |

“盘中观察／日终确认／后续确认”另作为观察阶段，不与上述三种结果混成一个状态。盘中某条件临时满足，可以在收盘时不满足；缺少分钟数据只影响盘中判断，不意味着已完成日线也无法使用。

若以后采用“五项全部满足”的严格筛选，只能在所选规则的必需项全部可判定且满足时输出完整确认；任一必需项未知不能按通过处理。增强项缺失应只标记该增强判断不可得，不扩大成所有核心条件都不可用。具体硬条件和增强条件选择须连同参数保留，本文不预设唯一组合。

执行条件按第 6.6 节分别汇总，检查通过不等同于实际成交或交易指令。形态结果、执行检查和后续真实委托／成交结果应能分别追溯；执行检查失败或过期不改变原始形态证据。

### 8.2 当时已知的信息边界

- 事前平台、历史量能、龙头名单：使用截止 t-1 或预先明确的观察时点的数据。
- 当日确认：完整当日行情到达后，才可使用最终收盘价、全日成交量和最终市场广度。
- 后续确认：次日是否回踩不破、未来三日是否持续放量，只能在相应日期另行更新，保留原始突破当日判断。
- 以后若检验交易结果，使用当日收盘后才能形成的信号，不能同时假定已提前按当天收盘价完成交易；成交可行性应另行建模。
- 可交易性：使用计划执行前当时已知的盘口、账户、委托、费用和交易规则。以今天的盘口或账户可用数量回填历史，不能证明历史订单当时可执行。

### 8.3 需要用真实数据验证的具体问题

1. 平台窗口、宽度、漂移、压力容差及测试次数，分别对哪些波动类型有效？
2. 1.5 倍／2 倍量、历史分位、换手率和绝对成交额，哪种组合能区分有效参与与低基数放量？
3. 龙头候选名单能否按当时数据重建，多龙头数量和普通成员跟随是否分别提供信息？
4. 长均线全向上是否过度延迟底部反转信号，是否更适合上升趋势中的整理突破？
5. 大盘方向、广度、量能和相对强弱各自是否增加判断价值，是否重复使用相同信息？
6. 历史板块、股本、交易状态、复权快照及分钟同时刻基准是否确实可得，缺失是否导致样本偏向？
7. 指定方向、数量、限价及执行阶段下，盘口覆盖、规模比率、账户预占和成本模型能否解释实际成交／拒单情况？静态估算与真实执行误差有多大？

这些问题决定后续参数验证与样本选择；本文完成的是五项形态条件及独立可交易性检查的数据需求和可核查定义，不报告预测准确率、胜率、收益或保证成交的结论。
