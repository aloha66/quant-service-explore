# 板块独立研究与比较

模式 Operate。新手单人研究；延续个股原型的图表与记录布局。根据第二轮体验和 Jev 范围评审，探索加入市场参照是否改变对板块的理解。采用真实 2025 年快照；不生成研究判断、不扩展个股关联或交易功能。

## Direction contract

THESIS: 先留下板块自身理解，再揭示比较信息，保留两次记录供回看；每一步只增加一种依据。

OWN-WORLD: 沿用 docs/prototypes/stock-research-first/DESIGN.md 的浅底、深绿操作色、系统中文字体、原有图表与文字记录风格。

STORY: 先读指数对象口径、看日线；保存自身判断后增加沪深300参照；记录影响和继续研究意图；一次揭晓后分别保存案例回看与原型发现。

FIRST VIEWPORT: 顶部一句试验问题和状态；主体左侧约三分之二为板块日线，右侧为当前步骤的记录。比较图在需要时进入原图下方，原记录始终可读。窄屏单列。

FORM: 沿用既有研究工作台，新增顺序比较步骤。用户要求基于已有反馈直接推进，属于范围明确的原型延伸，不做视觉方案评选；seed 不适用。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

未决：比较是否帮助理解而非诱导方向；改变条件能否写清参照和期限；记录负担；指数代理和历史成员缺失是否影响研究。
