# 确定分段平台的边界稳定、抬底幅度和宽度阈值

## Problem Statement

首期平台已确定使用三段高低价极值比较，但上下沿稳定、抬底幅度及平台宽度的判定阈值尚未确定。用户要求将这三类阈值作为待办，后续继续讨论；它们仍是首期平台成立规则的待补齐项，不能据此取消结构检查或只用窗口新高代替平台。

## Findings

- 来源：2026-09-18 本轮 grill-with-docs 的 Q8，用户选择方案 1，并要求把后续的上下沿稳定、抬底幅度和平台宽度阈值讨论加入 todo。
- 统计方法已固定：20 根有效日线分为 7／7／6，40 根为 14／13／13，60 根为 20／20／20；按时间先后分段，每段上沿取最高价最大值，下沿取最低价最小值。
- 全窗口 P、B 仍为整个窗口的最高／最低价，平台宽度沿用 `P / B - 1`；不暗中替换为分位数。
- 目标形态是横向箱体与抬底收敛整理；上下边界共同持续抬升的一般上行通道不属于本轮平台范围。
- 首套规则已选择统一、透明、可配置的参数，两类形态分别定义结构条件，不按市场或波动类型另设首轮参数组。
- 收盘突破 1%、等待区间、样本跨度与平台复用期已另行确认；这些数值不自动成为边界稳定或抬底幅度阈值。
- 现行要求见[五条件需求第 1.3 节](../docs/2026-09-09-volume-breakout-five-condition-data-requirements.md#13-需要计算并检测什么)。

## Proposed Solutions

1. 先给三类判定各定义可核查的相对变化量及统一试算阈值，再用横向箱体、抬底收敛、上行通道和尖刺样本检验误判边界。优点是容易核查，限制是初始数值需要真实样本验证。
2. 在同一已固定统计方法下，先建立按时间截断、保存输入证据的结构样本集，比较预先登记的阈值组合后提出首轮数值。需要先取得合格样本，不能以事后涨跌表现倒推平台定义。

两种路径均保留已确认的三段极值方法，不启用待办 002 的摆动高低点方案，也不按单次结果临时择优。

## Recommended Action

按用户要求暂存，后续继续确定三类阈值；在其完成前保留平台结构规则未闭合的状态，不宣称完整候选检测已可实施或通过验收。

## Acceptance Criteria

- [ ] 明确上沿稳定、横向箱体下沿稳定的计算式、分母及数值容差。
- [ ] 明确抬底收敛的逐段抬高幅度、是否允许局部回落，以及与横向箱体和上行通道的区分。
- [ ] 明确平台宽度阈值及适用形态、窗口，不隐式引入额外参数组。
- [ ] 规定等于阈值、价格分母非正、边界尖刺等情况，并与已确认的样本完整性规则一致。
- [ ] 使用人工边界例和可追溯行情样本核查判断，分别报告公式检查与真实样本验证结果。
- [ ] 将最终阈值、适用范围及验证限制同步到需求文档，必要时同步领域用语，再更新待办状态。
