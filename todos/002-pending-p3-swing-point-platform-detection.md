# 增加摆动高低点平台识别方案

## Problem Statement

首期平台识别已选择前、中、后三段边界比较，并结合宽度、漂移和独立上沿测试次数。用户要求将摆动高低点识别保留为后续待办，用于识别高点稳定、低点横向或抬高的结构，不扩大首期范围。

## Findings

- 来源：2026-09-17 本轮 grill-with-docs 的 Q2，用户确认“先实现1，2是todo”。
- 现行边界见[五条件需求第 1.3 节](../docs/2026-09-09-volume-breakout-five-condition-data-requirements.md#13-需要计算并检测什么)。
- 两类目标结构为横向箱体与抬底收敛整理，一般上行通道不属于平台。
- 若局部拐点依赖右侧行情确认，必须区分拐点发生日期与实际确认日期，不能在历史检测中提前使用未来数据。
- 首期分段方案及未来摆动高低点方案均未因此完成实现或样本验证。

## Proposed Solutions

1. 增加具有固定左右观察窗口的摆动高低点规则：易于逐点解释，但须接受确认延迟，并处理相等高低点、边界样本和停牌间隔。
2. 增加按预设价格反向幅度确认的摆动点规则：可适应不同长度的波段，但必须固定确认条件与版本，禁止把尚未确认、仍会移动的末端拐点用于正式历史信号。

方案与参数留待后续细化；先与分段方案做相同输入下的对照，明确替代或并列使用方式，不能按单次结果择优。

## Recommended Action

按用户选择保留为后续事项；首期先完成分段平台规则及其样本检验，再决定本项的实现方案与排期。

- [ ] 定义横向箱体、抬底收敛与一般上行通道的区分条件。
- [ ] 保存拐点发生日期、确认日期及当时可用输入，验证没有未来信息泄漏。
- [ ] 明确停牌空槽、未知缺口、短历史及输入修订的处理。
- [ ] 与首期分段方案进行同样本对照，登记方法版本与启用边界，保留原信号证据。
- [ ] 同步需求与相关领域用语，完成实现和样本验证后再标记完成。
