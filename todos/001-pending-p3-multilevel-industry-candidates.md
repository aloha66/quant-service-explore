# 扩展一级、二级、三级行业独立候选与分层排名

## Problem Statement

首期已确认一级行业用于概览、二级行业用于候选发现。用户要求把“一级、二级、三级均独立生成候选并分层排名”保留为后续待办；本项不扩大首期范围。

## Findings

- 来源：本次 grill-with-docs 讨论 Q21，用户选择首期方案 2，并要求方案 3 加入 todo。
- 现行边界见[五条件需求第 3.6 节](../docs/2026-09-09-volume-breakout-five-condition-data-requirements.md#36-板块发现与持续趋势跟踪)。
- 板块主趋势已选成员等权组合，改善／强势两类判断共用一条板块跟踪记录；本项应保留这些已确认规则。
- 具体行业分类来源、历史成员、层级关系与各层有效样本覆盖尚待验收，不能假定现有数据已齐备。

## Proposed Solutions

1. 在同一已验收分类体系内扩展一级与三级的独立候选检测，各层单独计算、展示、排名，并明确父子板块关联。可保留层级语义，但需要历史关系与覆盖证据。
2. 分阶段完成扩展：先补齐层级关系和数据验收，再依次启用一级、三级候选。最终范围相同，交付节奏可按数据能力安排。

不得把三级与二级混为一张无层级榜，也不能用“存在子行业候选”自动代替父行业自身条件判断。工作量需在分类来源及首期规则确定后评估。

## Recommended Action

待后续排期与方案细化；当前仅记录未来扩展需求，不执行采集、业务实现或发布。

## Acceptance Criteria

- [ ] 固定行业分类来源、版本、三个层级的稳定身份与历史父子关系。
- [ ] 一级、二级、三级分别生成候选并分层排名，保留各自成员、条件与覆盖率。
- [ ] 明确跨层重复关注的展示方式，汇总股票和成交额时不重复计算。
- [ ] 为小样本、历史成员变化、缺失和分类迁移规定可核查处理方式。
- [ ] 保留成员等权组合、改善／强势独立证据与单条板块跟踪记录的既有边界。
- [ ] 完成对应样本验证并同步需求、词汇表和文档索引，届时再将待办标为完成。
